Mao Embed SDK — 执行过程渲染 Mock 演示

纯前端 mock：不连后端，直接驱动 ChatStore 的 WS 事件流，用于验证执行过程（思考行 / 工具组 / 轮次折叠）的渲染与交互。

查看要点（与桌面端对话页对照）：
  • 完成任务后过程折叠为 已执行 N 个步骤，任务耗时 X 胶囊，最终回复常显；点击胶囊展开全过程（思考行、工具组、中间文本）。
  • 思考行显示「思考完成」，执行中显示「思考中…」+ 尾部滑动预览。
  • 工具组：单调用一张卡（带图标）；多调用折叠成「2次执行命令」组头，展开逐卡。
  • 工具卡展开：shell 终端块（$ 命令 + 输出 + exit 徽标）、read_file 行号内容、edit_file diff、网页搜索列表；右下「查看原始输入输出」。
  • 执行中：工具行右侧秒表与转圈；等待下一轮输出时气泡尾三点。
