### 后端

- **文件代理投递按客户端能力分层**：auth 帧新增 `capabilities` 能力声明，文件浏览请求优先投给声明了能力的执行端连接；旧版 mao-agent（未声明）不再白等超时，即时返回升级提示；全部客户端均不支持时返回明确的版本过旧文案。

### 终端 CLI（mao-agent）

- **支持远程浏览本地任务文件（只读）**：`local --serve` 常驻与交互模式（当前会话）均可接管文件浏览请求（目录 / 读取 / 搜索 / 文件引用），移动端 / 浏览器可浏览 CLI 执行端设备上的真实文件；已知差异：终端不缩放大图片，超过回帧上限的图片会提示「文件过大」；旧版收到升级提示，请升级 mao-agent 后使用。
