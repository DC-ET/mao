### 后端

- **仓库内置技能随部署进入系统 Skills**：`skills/builtin.json` 白名单点名的技能与 `skills/bundled/` 下的技能随 `git pull` 发版自动出现在「系统 Skills」（`builtin=true`，如 `mao-cli`），无需拷贝或上传；技能视图按现有指纹在下次会话重建。内置技能不可在后台删除（409）、不可被上传或 bundle 导入覆盖（409 / exists-skip）；个人技能沿用同名 409。`SKILLS_DIR` 与内置技能根重叠时拒绝启动（防写坏 git 检出）。
- **系统技能删除加第二道防线**：删除目标不在 `SKILLS_DIR` 内时拒绝（500）且不删除，避免误删 git 检出。
