### 后端

- **终端断线重连改为增量回放**：`RemoteTerminal` 按原始字节维护输出序号，`attach` 可带 `fromSeq`，只补发缺失部分；`attached` 帧带 `replay`（`full` / `delta`）与当前序号，`output` 帧带帧首 / 帧尾序号。切任务、短暂断线、回前台不再每次清屏，xterm 本地 scrollback 得以保留；缓冲已滚过去或发生过背压丢帧时仍全量回放。中继终端复用同一实现，执行端无需改动。

### 前端（桌面 / Web / 安卓）

- **手机 / 平板终端可用性修复**：xterm 6.0 自身没有触摸滚动，新增单指滑动翻历史（带惯性、松手减速），普通缓冲滚 viewport、全屏程序发方向键、开了鼠标上报的程序（tmux mouse、vim `mouse=a`）合成滚轮；右下角新增「回到底部」，离开底部期间有新输出带圆点。
- **按键条扩展到手机浏览器**：安卓壳与手机 / 平板浏览器都显示两行按键条（Esc / Tab / Ctrl / Alt / 方向键 / ⌨；^C / `|` / `~` / `/` / `-` / Home / End / 粘贴 / `⋯`），`⋯` 含 PgUp / PgDn / ⇧Tab / ^D / ^Z / ^L / ^R / ^A / ^E / 选择文本 / 搜索 / 字号 / 最大化 / 收起。方向键与 Page 键长按连发；点按键不再收起软键盘。
- **Ctrl / Alt 粘滞键对软键盘生效**：改在 `terminal.onData` 层处理（安卓软键盘常上报 `Unidentified / 229`，旧实现的 `keydown` 只对外接键盘有效）；单击单次、再点锁定。单字符才做 Ctrl 转换（避免 Gboard 整词提交把 `cat` 变成 `^C` + `at`），Alt 只对可打印 ASCII 加前缀；粘贴与按键条走原始通道，不会被二次改写。
- **粘贴与复制**：粘贴统一走 `terminal.paste()`（bracketed paste、换行规范化）；WebView 拒绝读剪贴板时弹出「粘贴到终端」对话框，长按系统菜单粘贴；多行且应用没开 bracketed paste 时二次确认。新增「选择文本」快照层，可长按选择、系统菜单复制或「复制全部」。
- **面板布局与字号**：触屏端默认高度为可视区 50%，可最大化 / 还原；`A− / A+` 与双指捏合调字号（10–18px），改字号后自动 fit 并同步 PTY 尺寸；软键盘弹出时按 `visualViewport` 钳制高度并避让（`Layout` 改用 `dvh`）；打开面板 / 切标签不再自动弹键盘。
- **标签栏与入口**：触屏端标签更高、关闭按钮命中区 32px，关闭前确认；新建 / 关闭按钮补 `aria-label`；桌面头部新增搜索与最大化按钮并补 `aria-label`；触屏端搜索在按键条 `⋯` 里。
- **回前台与断线恢复**：终端 WS 在 `visibilitychange` / `online` 时立即探活，连接已死立即重连（重置退避），活着补一次 ping；触屏端把面板状态记到 sessionStorage，整页刷新后自动恢复面板与标签；断线期间面板顶部显示「终端重连中…」。
