### 后端

- **角色可以按 Agent 追加系统技能**：会话生效的系统技能是 Agent 共用名单再加上当前发言者各角色的授权。同一技能只出现一次；个人技能仍然覆盖同名系统技能。删除系统技能或删除 Agent 时，对应授权一起摘掉。

### 管理后台

- **角色权限页可以维护岗位技能**：权限和技能分开保存。技能列表标出每个系统技能被哪些角色、在哪些 Agent 上追加。Agent 表单里的技能说明改为「所有使用者共用」。

### 前端（桌面 / Web / 安卓）

- **斜杠菜单按当前输入框的 Agent 过滤系统技能**：新建任务、已有会话、边路任务和消息编辑各自用自己的 Agent。没有选定 Agent 时仍列出全部系统技能。

### 终端 CLI（mao-cli）

- **`mao role skills` / `mao role assign-skills`**：查看或覆盖保存角色追加的系统技能。省略 `--grants` 不会清空，显式空字符串才会清空。
