### 后端

- **新增文件多选打包下载端点**：`POST /v1/files/workspace-download-multi-zip`（会话 CLOUD）与 `POST /v1/files/owned-download-multi-zip`（工作区总览），把选中的文件 / 目录合并为一个 zip 一次下发；沿用 1GB 大小上限与路径沙箱，单目录 zip 打包逻辑重构为通用多源打包（行为不变）。

### 前端（桌面 / Web / 安卓）

- **文件管理多选下载改为合并 zip 一次保存**：此前多选后点「下载」只有第一个文件真正保存、其余静默丢失（Chromium 对无手势后续下载静默丢弃）；现在多选（≥2 项）合并为一个 zip（`工作区名-YYYYMMDD-HHmm.zip`）一次保存，文件与目录可混合、目录保持内部结构。
- **修复 LOCAL 模式点「下载」毫无反应**：当前模式无下载能力时明确提示「当前模式不支持下载」，覆盖底部工具栏、右键多选与右键「下载此目录（zip）」。
- **修复下载偶发失败**：blob URL 从点击后立即回收改为延迟 1s 回收，消除「浏览器尚未开始读取就注销 URL」的竞态。
