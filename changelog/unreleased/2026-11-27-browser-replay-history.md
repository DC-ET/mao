### 后端

- **新增浏览器回放跨会话列表**：新增 `GET /v1/browser-live/replays`（本人全部云端录制，默认最近 30 天，可按时间范围 / 日期筛选、分页、`refresh=1` 强制刷新）与管理端 `GET /v1/admin/browser-replays`（跨用户全局列表，可按用户 / Agent / 会话标题 / 时间筛选；`session:read` 权限 + 全局审计留痕，逐帧请求按路径豁免防刷屏），以及管理端 `timeline` / `frames` 只读端点。数据源仍是 runtime 目录里的录制文件（零数据库迁移），列表带 30 秒缓存、liveId 时间戳预过滤与候选 / 读取上限截断提示；本地执行（LOCAL）会话的录制在用户设备上，管理端接口一律拒答。本人列表按会话归属收敛，群聊等落在发言者运行目录下的他人会话不会出现。

### 管理后台

- **新增「浏览器回放」页面**（「运行」组）：跨用户列出全部云端录制，支持按用户 / Agent / 时间范围 / 会话标题筛选，会话标题可跳转会话详情，点开即可播放（时间轴 / 倍速 / 逐帧，帧缺失按清理占位）。页面固定提示「录制可能包含登录态敏感信息，访问会记录审计；LOCAL 会话的录制保存在用户设备上，管理端不可见」。

### 前端（桌面 / Web / 安卓）

- **设置页新增「浏览器回放」**：列出本人全部录制（Electron 含本机 LOCAL 录制，Web / 安卓仅云端），支持时间范围（默认 30 天）/ 执行模式 / 会话标题关键词筛选，「播放」打开弹窗直接定位该场，「打开会话」跳转对应任务；本机录制只在这台设备可见，云端录制超过 200 场或本机扫描达到上限时提示缩小时间范围；不归属当前账号的本机录制不会展示。

### 桌面 Electron

- **新增本机回放扫描 IPC**：设置页「浏览器回放」在 Electron 下扫描 `~/.mao/runtime/<当前服务器>/` 下的录制目录（只扫当前服务器 hostKey，防跨服务器会话号撞号；会话目录须为数字、场次目录须匹配 `L<时间戳>`，单次上限 2000 场、枚举 2000 个会话目录，触顶返回截断标记），与云端列表按「会话 + 场次 + 模式」去重合并。**需要安装新版桌面客户端**（改了主进程 / preload，不能只发 `desktop/dist`）。
