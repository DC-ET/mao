### 后端

- **浏览器直播协作输入转发**：`/api/ws/stream` 新增 `browser_live_input` 上行帧——校验会话属主（60s 缓存免每批查库）+ 按会话事件数限速 + 非法批静默丢弃后转发 sidecar 注入 CDP `Input.*`；输入活跃的 5s 窗口内直播帧下发限速由 (6,12) 放宽到 (12,24)。输入内容零日志 / 零审计（按键可能含密码）。

### 前端（桌面 / Web / 安卓）

- **浏览器直播「协作操作」**：会话属主在直播 Tab 开启后，鼠标 / 滚轮 / 键盘（含中文输入法整段提交；macOS 的 Cmd 按远端 Ctrl 语义翻译）直接作用于 Agent 正在使用的浏览器，与 Agent 并发、无接管 / 暂停语义。本地显示 ghost 光标维持跟手感、「Agent 执行中」徽标提示命令可能交织、画面延迟超过 1.5s 有提示、Esc 退出；Shift/Ctrl+点击、Ctrl+滚轮缩放等组合键完整支持；开关不记忆状态，每次显式开启。
- **旧采集端自动降级**：会话内 sidecar 不支持输入注入时「协作操作」按钮置灰并提示「采集端升级后支持操作」，不影响观看与其他功能。
- **直播帧携带坐标元数据**：帧新增 `meta`（设备尺寸 / 页面缩放 / 滚动偏移，来自 CDP screencast 元数据），协作点击的坐标映射有据可依；顺带修正帧宽高上报恒为 0 的旧问题（现按 deviceWidth/deviceHeight 上报）。

### 桌面 Electron

- **LOCAL 协作输入直连与菜单快捷键屏蔽**：LOCAL 模式输入经主进程直 POST sidecar `/input`（旧 sidecar 返回 404 时自动降级提示）；协作键盘捕获期间临时屏蔽应用菜单加速键（Cmd+W / Ctrl+R 等，退出或失焦即恢复），避免发给远端的快捷键先关掉本地窗口。
