### 后端

- **压缩后保留任务台账**：复杂目标型任务长时间执行中途触发压缩后，模型侧的待办 id 全部丢失、`task_update` 无从调用，任务面板长期停在 0/N。现在压缩摘要指令要求以最近一次 task_* 工具结果为准，原样保留台账（每项 id / content / status 与当前 in_progress 项），压缩后可立即依据 id 补标。
- **任务台账每轮注入请求**：仿照 no-progress 提醒的注入方式，当前任务台账以 `<system-notice>` 追加在每次请求尾部（不落库）：压缩重载与执行开始以 DB 为权威重建，task_* 工具执行后以工具结果即时刷新（台账删空即清空）。未压缩的长任务里任务纪律与进度持续在场，模型不再需要从历史消息里重建清单。
