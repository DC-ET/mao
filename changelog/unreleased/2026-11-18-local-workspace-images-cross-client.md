### 后端

- **`workspace-download` 支持 LOCAL 会话按需委托执行端读取**：新增 `file_fetch` / `file_fetch_result` 委托帧（512KB 分片拼装，15s 总超时，per-user 在途软上限 8），服务端按需向绑定执行端读取工作区图片字节并回传，不落盘不存库。顺带修复一个安全缺口：LOCAL 会话的 workspace 服务端创建时不校验，workspace 文件端点族（下载 / 预览 / 读取 / 打包等）此前会直读该路径——图片下载改走按需委托，其余端点分流到执行端设备代理或明确拒绝，整族不再触碰服务器文件系统。

### 前端（桌面 / Web / 安卓）

- **本地任务正文图片在所有客户端渲染**：此前 LOCAL 会话正文里的工作区截图（`![x](screenshots/x.png)`）在桌面 / 浏览器 / 安卓全部显示「📎 原始路径」占位，现在与 CLOUD 会话同构解析为可查看地址（需执行端在线；离线或路径不存在时仍回退占位文本）。视口外图片懒加载，避免长消息多图一次性发起全部请求。查看本地图片时文件内容会经服务器中转、不存储。

### 桌面 Electron

- **新增 `local-read-workspace-bytes` 委托读取 IPC**：按会话 workspace + 相对路径在主进程拼装并做 containment 校验后读取文件字节（10MB 上限、realpath 口径防父级目录符号链接逃逸）。LOCAL 正文图片渲染依赖该 IPC——**旧版客户端壳需升级**，否则 LOCAL 图片回退占位文本。

### 终端 CLI（mao-agent）

- **支持 `file_fetch` 委托帧**：作为 LOCAL 会话执行端时按需读取本机工作区图片并分片回传（需升级到对应版本；信任边界 / 路径越界 / 非图片扩展名一律静默不回包，与技能同步的既有口径一致）。
