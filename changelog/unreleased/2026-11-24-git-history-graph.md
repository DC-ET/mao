### 后端

- **Git 提交历史返回父提交并支持全部分支**：`GET /v1/files/workspace-git-log` 每条提交新增 `parents`（父提交完整哈希，根提交为空数组），结果改为按日期排序且保证子提交在父提交之前（`--date-order`）；新增 `allBranches=true` 参数，返回全部本地 / 远端分支与标签上的提交（不含 stash），可与 `path`、`keyword` 同时使用。

### 前端（桌面 / Web / 安卓）

- **Git 历史显示提交图谱**：Git 管理器「历史」页每行左侧画出分支线与合并线，按列着色，合并提交为空心圆点；展开提交时文件清单左侧的线不断开。筛选栏新增「全部分支」开关，默认只看当前分支。按路径或提交信息筛选时不画图谱，并提示「筛选中不显示图谱」。
- **合并提交标题简化**：`Merge branch 'A' into 'B'`、`Merge pull request #N from A` 等默认合并标题显示为「A → B」「#N A」并弱化颜色，悬停可看原文。
- **修复历史行时间被挤成竖排**：分支 / 标签装饰较多的提交行，相对时间不再折成多行。

### 桌面 Electron

- **本地模式 Git 历史同样支持图谱与全部分支**：本地会话读取提交历史时同样返回父提交、按日期排序且子提交在前，并支持「全部分支」。
