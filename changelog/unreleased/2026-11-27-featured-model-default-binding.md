### 后端

- **图片 / 语音模型支持默认模型**：`is_default` 从「全局唯一默认（实际只有文本）」改为按 `model_type` 各一个默认，互不影响；设置图片 / 语音默认不再动文本默认。文本默认仍只影响新会话；图片默认影响未指定模型的 Agent 的 `generate_image` / `edit_image`，语音默认影响 `text_to_speech` 与微信语音回复（改默认后立即跟随）。无默认时保持「首个启用模型」的既有兜底，行为不变
- **Agent 可指定图片 / 语音模型**：Agent 新增 `imageModelId` / `audioModelId`（可空，创建 / 更新接口可传，null=跟随该类型默认）。绑定后该 Agent 的特色工具只使用绑定模型；绑定模型被停用 / 删除 / 类型或协议不匹配时不回退默认（fail-closed），对应工具在该 Agent 会话中自动隐藏。语音模型仅允许绑定 OpenAI 兼容协议
- **删除模型自动清理 Agent 绑定**：避免悬空 id；被删模型的绑定回退为跟随默认。模型类型变更在有 Agent 绑定或该模型是类型默认时被拒绝 / 强制取消默认，防止配置漂移；语音默认模型不允许改成非 OpenAI 兼容协议

### 管理后台

- **模型管理**：三个类型页签都可设置默认（文本=新会话默认；图片=未指定图片模型的 Agent 使用；语音=未指定语音模型的 Agent 与微信语音回复使用），「默认」筛选与默认标签扩展到全部页签；「客户端可选」仅文本模型展示
- **Agent 编辑**：特色工具每行新增「跟随默认模型 / 指定模型」下拉（选项含默认标记，来自 `/models/availability` 新增候选列表）；绑定模型失效时行内红色警示「已绑定模型不可用」；复制 Agent 会复制绑定
