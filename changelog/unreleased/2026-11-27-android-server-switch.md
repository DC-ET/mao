### 安卓原生

- **APK 可在应用内切换 Mao 站点**：启动加载超过 8 秒、登录页「服务器设置」、设置 →「服务器」以及长按桌面图标的快捷方式都能打开原生选择器；填写站点根后可先探测连通性再保存，地址持久化并立即重启生效，最多保留 10 条最近连接记录可一键回填。默认地址优先级为「已保存 → 构建期 `--server-url` → `capacitor.config.json` → 官方站点」。
- **支持 HTTP 内网站点（可选）**：默认只允许 HTTPS；勾选允许 HTTP 后会二次确认。HTTP 页面不是安全上下文，前端已为 Git 撤销摘要和剪贴板写入补兜底，但仍建议只在可信内网使用。
- **OTA 跟随当前站点**：壳从当前站点的 `/uploads/releases/android-latest.json` 检查和下载更新，切换站点后不再请求官方域。私有站只应托管官方签名 APK + 私有清单；自行构建的 APK 因签名不同无法覆盖安装，`versionCode` 不高于已装版本也会被拒绝。`build-apk.sh` 新增 `--server-url`、`--version-code`、`MAO_PUBLIC_BASE_URL`，可用 `--version-code` 显式抬高版本号并校验目标清单下限。
- **站点地址仅支持站点根**：`https://host/mao` 这类子路径会被拒绝并提示使用独立域名；输入 `/api`、`/api/v1` 会自动去掉，`443`/`80` 默认端口会省略。探测发现跨 origin 重定向时只允许保存最终地址，避免壳注入的 bridge 失效。
- **服务器设置健壮性**：探测失败改为可读文案（域名解析失败 / 超时 / 证书错误 / HTTP 状态），非法端口直接拒绝；保存当前已连接站点不再无谓重启；Android 15 顶栏与底部手势区适配；服务器地址与 HTTP 开关不进入系统备份。

### 前端（桌面 / Web / 安卓）

- **API / WebSocket / OTA 改为跟随当前站点 origin**：一份 `desktop/dist` 可部署到任意站点，同源私有站不再需要按域名修改 `VITE_API_BASE_URL` 重新构建；安卓切换服务器后请求、终端与更新清单都会跟随新站点。split-domain（SPA 与 API 不同源）仍需显式设置 `VITE_API_BASE_URL` / `VITE_WS_BASE_URL`；站点子路径不支持。
- **HTTP 站能力兜底**：`crypto.subtle` 不可用时 Git 撤销摘要改用纯 JS SHA-256；分享链接、部署命令、终端快照等剪贴板写入统一走 `copyText`，非安全上下文下回退到 `execCommand`，不再静默失败。
- **安卓服务器入口**：设置页按 `ServerConfig` 插件能力显示「服务器」，展示当前站点与是否允许 HTTP；老版本壳没有插件时自动隐藏入口，设置页直连时提示升级。
