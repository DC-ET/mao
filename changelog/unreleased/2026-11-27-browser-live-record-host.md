### 后端

- **修复 host 模式开启「浏览器操作录制」后没有任何回放**：录制开关此前只经容器 envelope 下发 `MAO_BROWSER_LIVE_RECORD`，而默认的 host 模式 shell 从不注入该变量，sidecar 始终按「不录」运行，客户端查不到任何回放。现在 host 模式在每条 shell 命令前按设置注入 / 撤销该变量（60 秒缓存），新启动的浏览器采集进程会正常落盘；已在运行的采集进程需等其退出（浏览器关闭 / 2h 上限）后生效，已开始的直播不补录。
