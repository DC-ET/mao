### 后端

- **本地任务文件树支持远程代理**：浏览器 / 移动端查看 LOCAL 会话的「文件」列表时，服务端按会话绑定的执行端设备定向转发文件浏览请求（目录 / 读取 / 搜索 / 文件引用清单），不再读服务端文件系统；未绑定执行端的存量会话返回登记引导文案，设备离线或仅有 CLI 执行端时返回明确中文提示；预览 / 下载 / 打包下载暂不支持并明确拒绝。

### 前端（桌面 / Web / 安卓）

- **修复移动端浏览本地任务文件列表报错**：此前浏览器 / 安卓打开 LOCAL 会话的「文件」页会显示英文 TypeError；现在已绑定执行端设备的会话可直接远程浏览设备上的真实文件（只读），未绑定的会话展示登记引导。
- **修正双机互看的文件来源**：桌面客户端打开其它设备创建的本地任务时，文件列表改为展示执行端设备上的文件（此前会误读本机同名路径）。
