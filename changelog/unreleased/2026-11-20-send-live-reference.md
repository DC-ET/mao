### 后端

- **`send_image` / `send_file` 改为工作区活引用，不再复制附件**：会话工作区内的文件（CLOUD 模式）与 uploads 里本人已上传的文件，投递时只记引用（`delivery.ref` = 会话工作区相对路径，或 `delivery.url` 指向 uploads 原地文件），不再往 uploads 写副本；对话页渲染时实时取数。超过单文件大小上限、空文件、图片魔数不支持、外部 http(s) 链接、非本站域名的上传地址等场景按原副本路径回退，行为与既有上限语义一致；取数口径与工作区下载接口同一套严格路径解析（含「团队经验」挂载排除），权限不变。分享页仍降级为占位，嵌入浮窗随 SDK 同步支持。

### 前端（桌面 / Web / 安卓）

- **对话页附件卡片支持活引用实时取数**：`send_image` / `send_file` 投递改为引用工作区文件或 uploads 原地文件，图片预览、文件预览 Tab 与下载都在渲染期实时解析取数 URL 并附带当前登录令牌（令牌不写入消息内容），文件在会话工作区里被改动后卡片展示的就是最新内容；下载失败时会提示业务错误而不是拿到一段报错 HTML。
- **Embed SDK 投递条同步支持活引用（0.3.4）**：嵌入浮窗的发送媒体投递条同样支持 ref 形态，图片与文件链接在渲染期拼取数 URL 与令牌，令牌轮换自动刷新，不再展示陈旧副本。
