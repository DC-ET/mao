### 后端

- **修复 task_update / task_delete 收到非数组 items 时静默按空数组处理**：此前模型参数抖动（把数组传成对象/字符串）会返回「假成功」（无 error 键，模型以为更新/删除已生效），实际什么都没发生；现与 task_create（0.0.341）同口径显式报错，空数组也报「items 不能为空」。
- **修复任务通知偏好在 webhook 密文解密失败时整体不可用**：`APP_NOTIFICATION_WEBHOOK_SECRET` 轮换/丢失后，偏好面板打不开、连「关闭通知」的响应都是错误；现解密失败降级为 maskedWebhook:null，保留 enabled/channel/webhookConfigured（与系统设置解密同契约）。
- **修复收件箱/通知链路截断切断 emoji 代理对**：任务标题、失败原因、飞书卡片/引用文本按 UTF-16 码元硬截断，边界落在代理对中间时落库变 U+FFFD 乱码；现统一走 clipByCodePoints 回退到完整码点边界（与微信分片同口径），覆盖 inbox、投递、调度器、飞书卡片/媒体 6 处位点。

### 安卓原生

- **修复 OTA 下载无完整性校验导致的误装**：弱网/代理中途正常断流时，半成品 APK 会被改名拉起安装（用户只看到「解析包错误」且重试永远失败）；200 空响应体时会把上次升级残留的旧包拉起安装并标记「已下载」，前端从此停止检查更新。现下载完成后校验 Content-Length 收满、空产物直接报错。

### 终端 CLI（mao-agent）

- **修复 REST 请求超时只覆盖到响应头**：服务端 stall / 持续 trickle body 时请求永不返回，`/exit` 收尾（markRead）会挂死进程；现超时信号同时覆盖响应体读取（与 HTTP MCP 同契约），超时报「请求超时」。
- **修复 401 响应体为非 JSON（反代 HTML 页）时跳过刷新/重登链**：挂在 nginx basic auth / WAF 后的站点会直接输出 `HTTP 401: <html>` 退出，而不触发重新登录流程；现三种响应体形态的 401 行为一致。
- **修复审批投票回声等待可能永久悬挂**：本地按键投票后回声丢失（服务端重启/断线/重发用尽）时工具一直卡到服务端超时；现回声等待加 30s 总上限（到时按本地选择收尾），且断线时立即收尾所有等待中的回声（对齐「等待远端审批的请求立刻失败」契约）。
- **修复 `mao-agent update` 在 Windows 上必然失败**：`spawnSync('npm')` 不带 shell 在 Windows 上 ENOENT（npm 是 .cmd），且失败点在源码已强制切到远端之后，留下半更新状态；现 npm 调用走 shell 形态，并在动源码树之前预检 npm。
- **修复登录凭据文件写入非原子**：`~/.mao/auth.json` 写盘中断会留下截断 JSON，下次启动静默回落并把 legacy 目录里数月前过期的旧凭据复活回当前登录态；现改为 tmp+rename 原子写，auth.json 存在但损坏时告警并按未登录处理，不再迁移 legacy。
