### 前端（桌面 / Web / 安卓）

- **Git 管理器界面改版**：顶部分支改为带分支图标的胶囊，跟踪分支、领先 / 落后提交数和远端状态（状态圆点）更醒目；拉取 / 推送 / 刷新收进一组分段按钮；「变更 / 历史 / 分支 / Stash / 对比」改为分段式切换，「变更」上直接显示待提交文件数；没有变更时显示「工作区很干净」的空状态；提交信息输入框和提交按钮的样式也一并优化。
- **Git 管理器各视图字体统一**：变更 / 历史 / 分支 / Stash / 对比五个视图统一为三档字号——列表主文本 13px、次要信息与按钮 12px、提交哈希与增删行数等标识 11px 等宽；分支名、文件名、仓库名不再使用偏大的等宽字体，修复各视图字体忽大忽小、粗细不一的问题。
