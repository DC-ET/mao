### 前端（桌面 / Web / 安卓）

- **一眼认出自己发的消息**：对话里用户消息改为淡主色气泡 + 深色字（跟随所选强调色），和无气泡的助手回复区分开，又比实心主色更清淡。
- **长回答时「我的问题」吸顶**：本轮问题滚出屏幕后，消息区右上角会浮出一枚胶囊「我的问题」，显示问题摘要，点击即跳回原问题并高亮。窗口窄于 768px 时不显示。
- **跳转高亮更克制**：从轮次目录 / 吸顶条 / 搜索跳到某条消息时，改为淡主色高亮；用户消息只圈气泡本身，不再整行铺一条芥末黄。
- **轮次目录按钮更好找**：消息区右缘的轮次目录把手加上竖排「目录」字样；悬停时保持不透明底色，不再透出下方控件叠成重影。
