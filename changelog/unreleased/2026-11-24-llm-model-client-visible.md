### 后端

- **模型可以设为「仅管理端可选」**：模型配置新增「客户端可选」开关（默认开启）。关闭后，客户端新建会话与切换模型的候选列表不再展示它，但 Agent 默认模型、飞书/钉钉/微信机器人、网页浮窗、系统参数（审批预审、压缩摘要等）与已绑定该模型的会话照常可用。默认模型必须保持客户端可选。

### 管理后台

- **模型列表标出「仅管理端」并可筛选**：名称列与移动端卡片显示标签，筛选栏新增「客户端可选」。新建/编辑对话框在「基本信息」里可切换该开关（勾选默认模型时禁用）。

### 前端（桌面 / Web / 安卓）

- **模型选择器只列客户端可选模型**：新建会话与会话内切换模型不再出现「仅管理端」模型。当前正在使用这类模型时（历史会话或 Agent 默认模型），下拉顶部显示带「仅管理端」标签的只读当前项。
- **新建会话默认模型改为 Agent 默认优先**：没手动选过模型时，优先使用所选 Agent 的默认模型，其次全局默认；手动选过之后切换 Agent 不再覆盖。后台配好的默认模型因此在客户端也真正生效。

### 终端 CLI（mao-cli / mao-agent）

- **`mao model` 支持 `--client-visible 0|1`**：`list` 可筛选、`create` 缺省可见、`update` 不传保持原值；`list-active` 输出带 `clientVisible`。
- **`mao chat` 的模型候选改为客户端口径**：只列客户端可选模型；显式 `--model <id>` 与配置里的默认模型 id 不受可见性限制。

### 上线注意

- 先发布后端与客户端，再在管理后台把模型设为「仅管理端」。老客户端仍会拿到全量列表，此时选隐藏模型新建会话会提示「该模型不对客户端开放」。
