### 后端

- **在线设备快照带上客户端自报版本**：WS 认证首帧可以带 `clientVersion`。服务端记在连接上，并随 `GET /v1/statistics/online-devices` 返回。缺省或不是短版本串时记为空，不拒绝连接。

### 管理后台

- **在线设备列表显示客户端版本**：写在「额外信息」里。桌面是已安装的壳版本，安卓是 APK 版本，浏览器是当前页面版本，终端 CLI 是 mao-agent 版本，页面嵌入是 SDK 版本。还没上报的旧客户端不写这一行。

### 前端（桌面 / Web / 安卓）

- **连接时上报客户端版本**：桌面上报已安装的壳版本，安卓上报 APK 版本，浏览器上报当前页面的构建版本。壳版本读不到时退回页面版本，不拖住连接。页面嵌入 SDK 上报自身版本。

### 终端 CLI（mao-agent）

- **连接时上报 CLI 版本**：认证首帧携带 mao-agent 的包版本。
