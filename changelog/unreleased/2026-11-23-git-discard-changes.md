### 后端

- **新增撤销未提交改动接口**：`POST /api/v1/files/workspace-git-discard`（仅 CLOUD 会话），可撤全部或指定文件。已跟踪文件回到最近一次提交，未跟踪或仅暂存的新文件被删除，忽略文件保留；合并 / 变基 / 拣选进行中或有未解决冲突时拒绝；嵌套仓库目录与子模块跳过；「撤销全部」须带确认清单摘要，确认后清单有变化即拒绝。活动记录类型 `GIT_DISCARD`。

### 前端（桌面 / Web / 安卓）

- **Git 管理器「变更」页可撤销改动**：提交按钮左侧「撤销全部」、文件行撤销图标、右键「撤销此改动 / 撤销此目录的改动」，均先二次确认；Agent 运行中确认框会追加提醒。侧边栏 Git 页不变。

### 桌面 Electron

- **本地模式同样支持撤销改动**：新增 `git-discard` IPC，规则与云端一致，并照常记入会话活动。
