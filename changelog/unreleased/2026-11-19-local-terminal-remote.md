### 后端

- **本地任务终端跨端开放（中继终端）**：LOCAL 任务的终端不再只在桌面客户端可用——绑定设备的桌面客户端或 mao-agent 在线时，浏览器 / 安卓 / 其它电脑均可打开执行端本机 shell（PTY 跑在绑定设备上，服务器只登记转发），不另设本机允许开关；桌面客户端优先于 mao-agent，主机短暂断开 60 秒内重连保留原 shell；配额 / 回收 / 任务删除级联与云端终端共用同一套；删除会话时云端与中继终端一起关闭。

### 前端（桌面 / Web / 安卓）

- **终端按钮可用性矩阵升级**：LOCAL 任务的终端按钮按绑定设备的主机状态给出明确文案（未登记 / 设备离线 / 桌面客户端过旧 / mao-agent 过旧 / 双端均过旧各有固定提示），主机在线即启用；Electron 查看绑定在其它设备上的 LOCAL 任务不再误开本机 shell（收掉「错机器 shell」缺口）；任务列表分组按钮不再用桌面客户端探针，非执行端直接创建中继终端。

### 桌面 Electron

- **桌面客户端作为终端主机**：主进程新增 `/api/ws/terminal-host` 主机连接，替手机 / 浏览器在本机起中继 PTY（与本机 IPC 终端完全隔离）；账号切换自动终止旧账号的 shell，登出清理，页面刷新不影响手机上正在使用的 shell。

### 终端 CLI（mao-agent）

- **mao-agent 作为终端主机**：`local --serve` 常驻与交互式 LOCAL 模式均可作为中继终端主机（仅 LOCAL 模式；CLOUD 不启动）；node-pty 为可选依赖，安装失败时主机降级为「终端启动失败」，不影响工具执行与文件代理。
