### 后端

- **经验库列表接口参数化并新增两个只读端点**：`GET /agents/:id/experience-library/docs` 支持分页 / 排序 / 关键词与 tag 搜索 / 验证与更新日期区间 / 异常文档筛选 / 分月或分关键词分组计数（响应不再携带 `indexContent`）；新增 `GET /agents/:id/experience-library/index`（索引原文与条数）与 `GET /agents/experience-library/overview`（跨库统计，识别 Agent 已删除的孤儿库，需 `agent:read`）；库目录扫描重构为单次（原列表请求新鲜路径 2 次、陈旧路径 3 次扫描收敛为 1 次），索引刷新与挂载行为不变。

### 管理后台

- **团队经验库管理从弹窗升级为独立页面「能力 → 经验库管理」**：三栏工作台（跨 Agent 库列表 / 文档列表 / 阅读编辑器），文档列表支持搜索、关键词标签与日期筛选、异常文档巡检、排序、分月或分关键词分组与分页；经验文档与自动索引均支持 Markdown 渲染态 / 源码态阅读，编辑保存保留撞名覆盖确认与空内容拦截；URL 携带库、文档、页码与筛选条件，刷新或分享可完整还原；Agent 列表行内「经验库」按钮改为直达该 Agent 的库页面。
