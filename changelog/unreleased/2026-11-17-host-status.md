### 后端

- **管理后台可查看部署机当前资源**：新增 `GET /v1/statistics/host`（权限 `analytics:read`）。返回后端所在机器的 CPU 利用率、等待磁盘时间与 1/5/15 分钟负载、内存、后端进程（常驻内存、堆、事件循环延迟、文件描述符、进程运行时长）、按挂载点去重后的磁盘容量与 inode、整机磁盘读写速率，以及 mao 运行时容器数量和 Docker 镜像 / 卷 / 构建缓存占用。另有 `GET /v1/statistics/host/trend`，只返回当前这一点的 CPU 和内存，供页面折线每秒采样；不落库，无新增表。Docker 不可用时容器数和镜像占用标明原因，不把 0 当成「没有」；CPU、内存、进程和硬盘照常返回。

### 管理后台

- **新增「主机状态」菜单**：与用量分析、在线设备同级（权限 `analytics:read`）。CPU 和内存各一张折线，打开页面后每秒一个点，只在浏览器里保留最近 5 分钟，离开页面停止。硬盘、容器和进程默认不自动刷新，页头可选关闭、5 秒、10 秒、30 秒或 1 分钟，选择不记住。有系统设置读权限时可以跳到容器管理。

### 终端 CLI（mao-cli）

- **新增 `mao runtime host`**：读取同一份主机快照。
