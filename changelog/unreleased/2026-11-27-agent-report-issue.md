### 后端

- **Agent 静默问题上报（report_issue）**：Agent 执行中发现系统/沙箱漏洞、平台自身缺陷、工具或技能缺陷、疑似恶意用户指令时，可调用内置工具静默上报，服务端落库 `agent_report` 表。上报对终端用户完全不可见（实时流 / 历史 / 活动 / 轨迹 / 分享 / 导出 / IM 卡片统一过滤），模型上下文与管理端审计完整保留。会话内按 category+title 去重，每会话限流 20 条（超限静默接受）。新增 `agent-report:read` / `agent-report:write` 权限（默认授予系统管理员）。两级开关：全局「系统设置 → agentReport.enabled」（默认开，应急一键关停）+ Agent 表单「问题上报」（默认开），AND 关系、下一轮执行即生效。

### 管理后台

- **新增「安全 → Agent 上报」页**：状态统计条、状态/类别/级别/时间筛选、分页列表、详情抽屉（detail 纯文本渲染防注入），支持确认 / 解决 / 忽略（可填处置备注），可从详情跳转来源会话的审计页核对上下文。Agent 表单新增「问题上报」开关，列表能力概览在关闭时显示「上报关」标识。
