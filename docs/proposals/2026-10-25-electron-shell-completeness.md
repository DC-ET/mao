# 提案：Electron 壳补完 —— LOCAL 模式从「能干活」到「常驻桌面」

> LOCAL 用户把 Mao 当本机干活工具，但 Electron 壳停在了「能干活」：文件递不进对话、关窗就与任务失联、没有常驻入口。执行边界越「近」（LOCAL），能力反而越窄（CLOUD 能传文件，LOCAL 不能）——桌面应用的基本盘缺了一角。

- 状态：方向已认可（2026-10-26），已细化技术方案待评审：[docs/plan/2026-10-26-electron-shell-completeness-technical-design.md](../plan/2026-10-26-electron-shell-completeness-technical-design.md)
- 日期：2026-10-25
- 提案总览：见 [docs/proposals/README.md](README.md)
- 规模：小~中（P1 约 2-3 人日、P2 约 2-3 人日、P3 约 1-2 人日；纯 desktop/electron 层，零后端零迁移）
- 关联：`desktop/electron/{main,preload}.cjs`、`ChatInput.vue`、设置页；不触安卓壳

## 1. 背景与现状

### 1.1 LOCAL 递不了文件（代码可查）

- `ChatInput.vue:978-979`：LOCAL 模式明确提示「本地模式不支持文件上传，请使用 @ 引用工作区文件」。
- `@` 引用只能选**工作区内**的文件（本机目录）；桌面、下载目录、邮箱附件这些「工作区外」的文件给不了 Agent。
- 图片反而能传（有粘贴压缩管线 + URL 注入先例，0.0.336），任意文件不行。
- 对比 CLOUD：走 `/v1/upload` 什么都能传。**结果是云端比本地更顺手，与 LOCAL「数据不出本机」的卖点相悖的那部分体验缺口，恰恰赶跑了最看重这条卖点的用户。**

### 1.2 壳能力缺席（代码可查）

`desktop/electron/main.cjs`（2520 行）内零命中以下能力：

| 缺席能力 | 用户的实际体验 |
|---|---|
| Tray 托盘 / 关窗最小化 | 关窗即退出；任务在服务器跑 20 分钟，窗口一关完成与否就没人告诉你了 |
| 主进程系统通知 | 现在只有渲染层 `new Notification()`（`useInboxSystemNotify.ts:130`），窗口关闭即失效——收件箱、每日摘要、失焦补通知的消息面已铺满（0.0.235 起），唯独「壳」接不住 |
| globalShortcut 全局快捷键 | 想看一眼任务状态得先找到窗口 |
| setLoginItemSettings 开机自启 | 每天手动开 |
| 应用角标 setBadgeCount | 不看窗口不知道有未读 |

### 1.3 一个真实场景

用户把「整理这个月的报销发票」丢给 Agent，然后关掉窗口去做别的。20 分钟后 Agent 卡在一个待审批操作——没有托盘、没有通知、没有角标，任务静默挂到晚上。第二天他学乖了：开着窗口干等，或者干脆继续用别的工具。

## 2. 目标 / 非目标

**目标**

1. **P1 LOCAL 附件**：拖拽 / 选择任意文件 → 主进程拷入当前工作区固定子目录 → 注入 `@` 引用节点，Agent 经既有 LOCAL 文件工具读取。**文件全程不出本机**（不走服务端上传），与 LOCAL 数据边界一致。
2. **P2 壳常驻**：托盘（显示 / 隐藏 / 新建任务 / 退出）；关窗行为设置项（默认退出，可选最小化到托盘）；主进程系统通知（渲染层经 IPC 触发，窗口销毁仍可达，沿用收件箱偏好开关）；应用角标（收件箱未读数，平台支持才启用）。
3. **P3 快捷与自启**：全局快捷键唤起 / 隐藏窗口（可改可关）；开机自启（设置项）。
4. 设置页新增「桌面」分区（仅 Electron 显示，与既有「服务器」分区同模式）。

**非目标**

- 不做全局快捷键「快速发送小窗」（独立小窗的生命周期是另一个量级，先验证唤起需求）。
- 不做深链协议注册（`mao://`）。
- 不碰安卓壳（安卓系统推送是既有排除项；本提案全部在 Electron）。
- 不承诺 Linux 发行版托盘适配（文档注明 libappindicator 依赖即可）。
- 不新增服务端能力（上传 / 通知 / 收件箱全部复用既有）。

## 3. 与已否决 / 已排除方向的边界

| 方向 | 本提案为何不是它 |
|---|---|
| 执行节点注册（2026-10-25 否决） | 那是把 LOCAL 泛化到任意机器（新执行面 + 节点凭据安全模型）；本提案不新增任何执行面，只把现有单机 Electron 用顺。 |
| 安卓原生推送（README 排除） | 平台不同（Electron），机制不同（系统通知 vs 推送服务），不沾边。 |
| 出站订阅 / 邮件渠道（已实施） | 那些是「消息走出去」；本提案是「壳把消息接住」，互为补充。 |

## 4. 技术方案

### 4.1 LOCAL 附件（P1，核心）

- 入口：ChatInput 既有拖拽 / 选择链路放开 LOCAL 分支（Electron 客户端限定；Web 下的 LOCAL 不存在）。
- 流程：渲染层拿到文件路径 → IPC 交主进程 → 拷贝进当前工作区固定子目录 `.mao/attachments/`（重名加序号后缀）→ 返回工作区内相对路径 → 输入框注入 `@` 引用节点（与手输 `@` 走同一补全链路）。
- **数据边界**：纯本机文件拷贝，不经 `/v1/upload`、不经服务端——Agent 用既有 LOCAL 文件工具在工作区内读到，语义自洽（工作区就是本机目录）。
- git 工作区：会话创建 / 首次附件时把 `.mao/` 写入 `.git/info/exclude`（先例：团队经验目录，0.0.342 同机制），不弄脏 git status。
- 约束沿用服务端上传配置的大小上限；拒绝符号链接与目录拖入；路径固定在工作区内，无逃逸面。

### 4.2 壳常驻（P2）

- 托盘：图标 + 菜单（显示主窗 / 新建任务 / 退出）；点击图标 toggle 显示。
- 关窗行为：设置项三态（退出 / 最小化到托盘 / 询问）；默认维持现状（退出），避免改变存量用户预期。
- 主进程通知：新增 IPC 通道，渲染层把「该弹通知」的判定结果（沿用现有失焦判定与收件箱偏好）交主进程 `new Notification()` 发出——窗口已销毁也能弹；macOS 首次触发做系统授权引导。
- 角标：收件箱未读数（服务端为权威的既有口径）→ `setBadgeCount` / Windows 托盘角标贴图；平台不支持静默跳过。

### 4.3 快捷与自启（P3）

- 全局快捷键：默认 `Alt+Shift+M`（可改可关）唤起 / 隐藏主窗；注册失败（冲突）静默降级并在设置页提示。
- 开机自启：`setLoginItemSettings({ openAsHidden: true })` + 设置项，与托盘配合成完整常驻链。

**改动面**

|---|---|---|
| desktop/electron | `main.cjs`（托盘 / 通知 / 快捷键 / 自启 / 附件拷贝）、`preload.cjs`（IPC 暴露） | 主要工作量 |

## 6. 风险与开放问题

| 问题 | 风险 | 推荐默认 |
|---|---|---|
| 附件目录与 Agent 写操作冲突 | 低 | `.mao/` 前缀明确平台保留；exclude 防误提交；Agent 误删不影响后续（重新拷贝即可） |
| 工作区只读 / 磁盘满 | 低 | 拷贝失败降级为现状提示（「请使用 @ 引用」），不阻断输入 |
| macOS 通知授权被拒 | 中 | 首次触发引导到系统设置；被拒后设置页显示状态 |
| 关窗最小化与登出清理语义冲突 | 低 | 登出动作仍彻底退出并清理（auth store 既有全量清理链不动）；仅关窗行为可配 |
| 托盘三平台差异 | 中 | mac 红绿灯不占用、win 托盘区、linux libappindicator——冒烟清单化，不做发行版兜底 |
| Electron 包体 / 打包配置 | 低 | 仅用 Electron 内置 API，不新增原生依赖 |

**待确认决策**

1. 附件目录名与位置：工作区根 `.mao/attachments/`（推荐，exclude 一次覆盖）还是按会话分目录（隔离好但路径深）？建议前者 + 文件名带时间戳前缀。
2. 关窗默认行为：维持「退出」（存量预期）还是改为「最小化」（配合通知才闭环）？建议默认退出 + 首次启用托盘时弹一次性引导。
3. 通知是否区分类型（完成 / 审批 / 提问）：沿用收件箱既有偏好开关粒度（推荐），不另造一套。

## 7. 测试要点

- 附件：重名加序号、超上限拒绝、中文 / 空格文件名、符号链接与目录拖入拒绝、拷贝后 `@` 补全可选中、Agent 实际读到内容；git 工作区 `.mao/` 进 exclude 且 `git status` 干净。
- 托盘：显示 / 隐藏 / 新建任务 / 退出全菜单动作；关窗三态各按配置生效。
- 通知：窗口关闭后任务完成通知可达；偏好关闭后不再弹；macOS 授权拒绝路径。
- 角标：未读数增减同步；不支持平台无异常。
- 快捷键 / 自启：注册冲突降级；自启开启后重启拉起（人工冒烟）。
- 回归：Web 端（非 Electron）LOCAL 分支不出现、审批流 / 终端 / 文件工具不受影响。

## 8. 验收标准

1. LOCAL 会话：把桌面上任意文件拖进输入框 → Agent 读到并完成任务；全程文件不离开本机（抓包可证无上传）。
2. 关掉窗口：任务完成 / 待审批 / 待提问时系统通知照常到达，托盘可唤回窗口，角标显示未读。
3. 设置页「桌面」分区：关窗行为、快捷键、自启三项可配且即刻生效。
4. Web / 安卓端零感知（改动全部在 Electron 分支内）。
