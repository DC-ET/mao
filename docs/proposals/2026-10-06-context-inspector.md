# 提案：上下文透视与手动治理 —— 打开"模型到底看到了什么"的黑盒

- 状态：已转入实施（2026-10-06；技术方案见 [docs/plan/2026-10-06-context-inspector-technical-design.md](../plan/2026-10-06-context-inspector-technical-design.md)）
- 日期：2026-10-06
- 提案总览：见 `docs/proposals/README.md`

## 1. 背景与现状

上下文侧的可观测现状：

1. **有水位、无构成**：`TaskInspector.vue` 已显示 token 进度条（`onContextWindow` → ws 推送），`CompactionMarker.vue` 显示压缩事件。但"这一轮请求实际发送了什么"是黑盒——系统提示分节、注入了哪些长期记忆、压缩摘要内容、工具结果被截成什么样，都不可见。
2. **压缩全自动、无人工干预**：`compaction-service.ts` 锚点实测 tokens、阈值 `window * 0.8` 触发。用户"感觉 Agent 忘事了"时没有任何干预手段，只能等自动压缩或开新会话。
3. **记忆注入不可见**：长期记忆已上线自动注入，但"这次会话注入了哪些记忆条目"没有展示。记忆本身可在设置页管理，注入过程不可见——记忆被污染时用户无法定位是哪条记忆在作祟。

## 2. 目标 / 非目标

**目标**

1. 检查器新增"上下文"页签：展示下一轮请求的上下文组成明细——系统提示分节 token 占比、注入的记忆条目列表、压缩摘要、最近消息水位、工具结果截断标记。只读。
2. 手动治理动作：立即压缩（提前触发 compaction）、单会话关闭记忆注入（默认开）、压缩摘要全文可读。
3. 数据来自构建上下文的同一路径，保证"所见即所发"。

**非目标**

- 不做上下文编辑 / 删除单条消息（破坏 harness 不变量，风险大收益小）。
- 不做检索增强（RAG 已否决；本提案是透明化，不是知识库）。
- 不做跨会话上下文模板 / 预设。

## 3. 技术方案

### 3.1 上下文组成 manifest（P1）

- PromptEngine / ContextManager 构建上下文时同步产出结构化 manifest：`sections: [{ name, tokens, ref }]`（system-prompt 分节 / memory / compaction-summary / messages / tool-results-truncated）。
- 复用现有 ws 事件通道扩展推送（`onContextWindow` 同源，不新增轮询）；TaskInspector 渲染条形占比。
- 记忆条目带 id 关联：点击跳设置页长期记忆管理，形成"看到 → 定位 → 修改"闭环。

### 3.2 手动压缩与摘要可读（P2）

- WS 消息 `compact_now`：空闲时立即执行 `compactSession`；执行中则挂到本轮结束的轮次边界。CompactionMarker 点开可读摘要全文。

### 3.3 记忆开关与截断标记（P3）

- 会话级 `memory_injection` 开关（默认开），关闭后 manifest 不含 memory 节。
- 工具结果触发摘要截断时（`tool-result-summarizer.ts`）在对应消息气泡打标，点开看截断前后对比。

## 4. 分阶段实施

| 阶段 | 内容 | 规模 |
|---|---|---|
| P1 | manifest 产出 + ws 推送 + 检查器"上下文"页签 | 中 |
| P2 | 手动压缩 + 摘要全文可读 | 小 |
| P3 | 会话级记忆注入开关 + 截断标记 | 小 |

## 5. 风险与开放问题

- **manifest 开销**：构建时顺手产出、随既有事件推送，无额外查询；流式关闭 / 异常态不推。
- **"所见即所发"漂移**：manifest 必须在构建函数内产出（引用同一条数据），禁止事后重建——这是本提案唯一的硬不变量，测试锚定。
- **token 数口径**：manifest 用锚点估算值，与计费 token 有偏差，UI 标注"估算"。
- **敏感信息**：压缩摘要全文与工具结果展示复用站内同款脱敏管线（`$MAO_REDACTED` 语义），上下文页签不成为新的泄密面。
- **开放问题**：manifest 的粒度是否到"每条消息的 token 数"——P1 先到分节级，消息级等用户反馈再加。

## 6. 测试要点

- manifest 分节与真实请求体一致性（mock LLM 抓包比对分节边界与 token 量级）。
- 手动压缩在空闲 / 运行两态的行为；运行中挂轮次边界不丢事件。
- 记忆开关关闭后 manifest 无 memory 节、下一轮请求确实不注入。
- 摘要全文与截断对比的脱敏一致性（密钥不出现在任何新展示面）。
