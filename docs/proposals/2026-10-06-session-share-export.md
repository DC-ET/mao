# 提案：会话分享与导出 —— 任务结果走出会话列表

- 状态：已转入实施（2026-10-06；技术方案见 [docs/plan/2026-10-06-session-share-export-technical-design.md](../plan/2026-10-06-session-share-export-technical-design.md)）
- 日期：2026-10-06
- 评审修订：2026-10-06（冻结口径对齐技术方案的弱冻结语义；开放问题三项收口；渲染复用对齐技术方案决策 4）
- 提案总览：见 `docs/proposals/README.md`

## 1. 背景与现状

任务产出（结论、代码变更、排查过程）的常见去向是"给同事看"。今天只有三条路：截图、复制粘贴、或让同事开账号自己翻会话列表。具体缺口：

1. **没有只读出口**：message 表逐行存储（V001），`session-history-loader` 与 admin 的 `GET /v1/admin/sessions/:id/messages` 已能取全量消息，ToolCallCard / MessageBubble / FileChangePanel 渲染组件现成——缺的只是一条带权限的只读路由。
2. **没有结构化导出**：仅有的导出是 admin 的 LLM 调用 CSV 与 Agent Bundle，均与会话内容无关；贴进周报 / 事故复盘文档仍靠手工整理。
3. **飞书 / 钉钉回传只有结论**：通道推送是摘要式的，过程细节仍要点回站内——分享链接可以作为通道消息里的"查看详情"落点。

## 2. 目标 / 非目标

**目标**

1. 会话只读分享：生成快照链接，站内登录用户可打开只读视图（消息、工具调用、文件变更清单、最终回复）。快照 = 创建时刻的消息水位（弱冻结）：后续新消息不出现；属主撤回/删除消息后分享内容同步消失（语义细则见技术方案 §5.2）。
2. Markdown 导出：把一次任务（主会话或边路任务）导出为 .md（目标、最终结论、关键步骤、文件变更清单），便于贴进文档与周报。
3. 治理：分享的创建 / 访问记审计；属主可随时撤销链接。

**非目标**

- 不做站外匿名公开链接（自托管内网，登录态足够；带 token 的临时链接列为 P3 备选）。
- 不做评论 / 协同编辑（不是文档产品）。
- 不做可交互的运行回放器。

## 3. 技术方案

### 3.1 快照链接（P1）

- 表 `session_share`（id, share_token, session_id, message_watermark, created_by, revoked_at, view_count）。
- `GET /v1/share/:token`：校验登录 + 实例内有效，返回冻结消息集（watermark 截断）；访问计数与审计落库。
- desktop 新增只读路由：复用 MessageBubble / ToolCallCard 渲染（文件变更以 summary 列表呈现，不渲染 diff 正文），隐藏输入区与操作按钮；系统提示词、模型配置等 Agent 资产不出现在视图与接口返回中。

### 3.2 Markdown 导出（P2）

- 服务端模板渲染：任务目标（首条用户消息）→ 最终回复 → 关键步骤（工具调用摘要，含参数预览复用 toolDisplay 口径）→ 文件变更清单（`message_file_change` 聚合，引用相对路径，不内联全量 diff）。
- 入口：会话菜单"导出 Markdown"，边路任务同款。

### 3.3 通道与临时链接（P3）

- 飞书 / 钉钉回传消息附分享链接（走 P1 权限：点开的用户需登录）。
- 可选带过期时间的 token 链接，面向无账号的临时协作者（默认关闭，管理员可开）。

## 4. 分阶段实施

| 阶段 | 内容 | 规模 |
|---|---|---|
| P1 | session_share 表 + 快照端点 + 只读视图 | 中 |
| P2 | Markdown 导出 + 边路任务支持 | 小 |
| P3 | 通道消息附链接 + 可选临时 token 链接 | 小 |

## 5. 风险与开放问题

- **敏感信息扩散面**：分享视图与导出对工具结果走站内同款脱敏 / 摘要管线（`tool-result-summarizer` 截断口径一致）；密钥类内容（`$MAO_REDACTED`）不出现在任何导出物中。
- **快照 vs 权限**：已收口——分享视图校验链读取时判定属主账号状态，属主停用后链接即时失效（技术方案决策 10）。
- **数据量**：长会话快照全量返回可能很大——watermark 截断 + 前端分页加载复用历史加载器。
- **开放问题（已收口）**：边路任务分享只含自身、不带父会话上下文（技术方案决策 9）；导出是否需要"仅结论"极简模板不做，有使用反馈再议（技术方案非目标）。

## 6. 测试要点

- 越权 / 已撤销 / 不存在的 token 均明确报错；撤销立即生效。
- 快照冻结语义：分享后新消息不出现；watermark 之前的消息完整。
- 分享视图与导出不含系统提示词、模型配置、脱敏以外的密钥内容。
- Markdown 导出的步骤摘要与站内工具卡片口径一致（toolDisplay 同源）。
- 审计记录创建 / 访问 / 撤销三类事件。
