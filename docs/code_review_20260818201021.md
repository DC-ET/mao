## 问题列表

### 问题 1：【中】`handleRetryExecution` 缺少 `registry.subscribe` 调用

**严重程度**：中  
**代码位置**：`handleRetryExecution` 方法（约第 648–670 行）

**问题描述**：
在 `handleSendMessage`（第 287 行）、`handleEditAndResend`（第 468 行）、`executePersistedUserPrompt`（第 404 行）等所有其他执行启动路径中，都会在提交执行前调用 `this.deps.registry.subscribe(userId, sessionId)`，作为防御性订阅保活。但 `handleRetryExecution` 中缺少这一调用。

**影响**：
- 如果客户端在重试前因网络重连或页面切换等原因丢失了该会话的订阅，则重试开始后的所有流式事件（`session_status`、`content_delta`、`tool_call_start`、`session_list_update` 等）均无法送达客户端，导致界面停留在"重试中"但收不到任何更新。
- 虽然客户端正常操作时已通过 `subscribe` 消息完成订阅，但缺少防御性 subscribe 使得此路径与其他启动路径不一致，存在偶发可用性问题。

**修复建议**：
在 `this.executionClaims.add(sessionId);` 之后、`submitExecution` 之前，添加：
```typescript
this.deps.registry.subscribe(userId, sessionId);
```

### 问题 2：【中】`handleRetryExecution` 未处理 `LOCAL` 执行模式

**严重程度**：中（仅影响 LOCAL 模式用户）  
**代码位置**：`handleRetryExecution` 方法（约第 648–670 行）

**问题描述**：
`handleSendMessage`（第 270–280 行）和 `handleEditAndResend`（第 456–464 行）在启动执行前，对 `LOCAL` 模式有以下处理：
1. 调用 `this.deps.localToolSessionRegistry.setUserForSession(sessionId, userId)` 注册会话到用户的映射
2. 调用 `isConnected(sessionId)` 检查桌面端是否在线
3. 报告本地 skills 和 agentsMd

而 `handleRetryExecution` 完全跳过了这些步骤。`runRetryExecution` 中也跳过了 skill sync 和 MCP sync（这是有意为之），但 `setUserForSession` 的缺失会导致：

**影响**：
- 当 Agent 在重试执行中发起 LOCAL 工具调用时，`LocalToolExecutor` 需要通过 `localToolSessionRegistry` 查找该 session 对应的用户 WebSocket 连接以发送工具请求。由于 `setUserForSession` 未被调用，工具请求将无法路由到正确的客户端，导致工具执行失败。
- 桌面端掉线重连的情况下，`isConnected` 检查的缺失会导致执行在无客户端可用时继续，工具调用会全部失败。

**修复建议**：
在 `handleRetryExecution` 中，`this.executionClaims.add(sessionId);` 之后，补充 LOCAL 模式处理：

```typescript
if (session.executionMode === 'LOCAL') {
  this.deps.localToolSessionRegistry.setUserForSession(sessionId, userId);
  if (!(await this.deps.localToolSessionRegistry.isConnected(sessionId))) {
    this.executionClaims.delete(sessionId);
    this.deps.registry.send(userId, wsEvent('error', sessionId, {
      message: 'Local client is not connected. Please ensure the desktop app is running.',
    }));
    return;
  }
  // 注意：不重新同步 skills — 复用已有会话上下文（有意为之）
}
```
