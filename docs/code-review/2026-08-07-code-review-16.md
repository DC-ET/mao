## 二、本轮独立复审补充发现的轻微问题

### 【轻微】1. `child_session_id` 参数解析无类型校验，非法值落入误导性报错

- **修复**：解析前校验 `isIntegralNumber()`，非整数返回「参数 child_session_id 必须是整数」；新增测试 `nonIntegerChildSessionIdRejected`。

### 【轻微】2. `summarizeDelegate` 对 `"child_session_id": null` 输出「#null」

- **修复**：`node.has(...) && !node.get(...).isNull()` 后再取文本。

### 【轻微】3. 追问成功后子会话 `title` 不更新

- **处理决定**：**不做**。首次委派标题已能标识子会话主题；多次追问后以审计记录区分轮次，属 UX 增强非功能缺口。

### 【轻微】4. 新增测试未覆盖「子代理执行报错（FAILED 分支）」

- **修复**：新增 `executionFailureWritesFailedTerminal`——`collector.onError` → 失败分支，断言补 ASSISTANT 失败消息 + FAILED 终态。

### 【轻微】5. Prompt 层对「从未委派过」的主代理也提示追问能力

- **处理决定**：**不做**。`getToolPrompt` 已强调「必须先从历史 delegate 结果取得 child_session_id」，风险很低。
