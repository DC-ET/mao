## 低严重程度

### 1. 模型输出先包裹引号、内部再带“标题：/Title:”前缀时清洗顺序失效

**代码位置**

- `backend-ts/src/session/session-title.service.ts:178-196`
- `backend-ts/src/session/session-title.service.spec.ts:41-46`

**触发条件**

模型返回常见的组合包装，例如：

```text
“标题：排查登录超时。”
```

或：

```text
"Title: Fix login timeout!"
```

当前实现先去除“标题：/Title:”前缀，再去除成对引号。由于前缀最初位于引号内部，第一次前缀匹配不会命中；移除引号后也没有再次清理前缀，最终会持久化为“标题：排查登录超时”或“Title: Fix login timeout”。

现有测试分别覆盖了 Markdown + 前缀 + 反引号，以及列表 + 前缀 +引号，但没有覆盖“引号包住前缀和标题整体”的组合，因此测试仍会通过。

**影响**

少量正常模型输出会保留业务明确要求清除的“标题：”或“Title:”包装，生成结果不符合验收标准，但不影响 Agent 主流程、持久化或并发安全。

**建议修复方向**

让包装清洗可处理嵌套组合，例如在去除成对引号后再次执行前缀清理，或以有限次数循环剥离 Markdown/前缀/成对引号，直到内容不再变化；仍然不要硬截断标题。补充上述中英文组合输出的单元测试。
