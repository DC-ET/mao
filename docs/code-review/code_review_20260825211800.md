## 二、修复清单（按严重级别）

### 严重（8 项，全部修复）
1. **S1 群聊@机器人永不触发**：`event-normalizer.ts` 原依赖飞书事件不存在的 `is_at_me` → 改为基于 mentions key 与 header.appId 比对
2. **S1 Lark SDK 事件格式**：SDK `RequestHandle.parse` 把 v2 事件 header/event 展开到顶层 → `normalizeHeader(root.header) ?? normalizeHeader(root)` 双兼容
3. **S1-A phase 终态永久静默**：`AgentLoop.isTerminalPhaseInDb` 检查 FAILED/CANCELLED，execute 前补 `updatePhase('RUNNING')`
4. **S1-B cancelFlag 污染**：flag 注册移到 `await previous` 之后（锁内），旧执行不再把取消传播给新代
5. **H1 媒体下载**：`downloadMedia` 选项 + create-app 流收集、大小限制、文件落盘
6. **H1 p2p 换绑锁内重查绕过 owner 过滤**：`createConversation` 增加 ownerUserId，锁内重查也带过滤
7. **H1 锁内缺代际前置校验**：`await previous` 后加 generation 校验（期间发现并修复自引入的 release() 缺失导致队列链中断）
8. **H2 会话复用热切换**：`applyFeishuBotConfig` 复用会话时更新 agentId/modelId

### 中（十余项，全部修复）
