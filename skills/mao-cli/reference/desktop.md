# 桌面 Web 端使用

桌面端是普通用户主入口：选 Agent、建任务、对话、工作区、定时任务、通知与设置。开发默认 `http://localhost:5201`；生产多为 `https://mao.example.com/`（管理后台在同域 `/admin/`）。

LOCAL 本机工具需 Electron，见 [electron.md](electron.md)。对话执行也可用 [mao-agent.md](mao-agent.md)。

## 进入方式

| 方式 | 适用 |
|------|------|
| 浏览器 Web | CLOUD 云端模式、Git 工作区、浏览器访问 |
| Electron | LOCAL 本地模式、本机目录与命令 |

macOS 窗口态顶栏左侧为红绿灯留白。进入全屏后红绿灯隐藏，左侧面板按钮贴到左边，与移动端同一位置；退出全屏后留白恢复。

## 首次使用引导

全新用户首次登录工作台（实例已配好模型与智能体）会弹出三步向导：选一个智能体、了解 CLOUD / LOCAL 执行边界、把一条示例任务预填进输入框（发送仍由自己点击）。完成或跳过后不再出现。实例尚未配模型 / 无可用智能体时，改为「等待管理员配置」提示页；任务列表与智能体选择器的空状态也会按具体原因给出指引。

## 任务列表与任务面板

左侧任务列表按工作区/项目分组；可搜索、折叠、加载更多。标准模式列表头部有多选入口：勾选多条任务后底部操作条一键批量归档，运行中（含等待审批 / 取消中 / 恢复中）与已归档的自动跳过并在提示里计数（「已归档 N 个，M 个跳过」），失败条目原位保留可重试。顶栏搜索（Ctrl/Cmd+K）可以按关键词找自己主会话和边路任务里的用户消息与助手回复，多个词用空格分开（或的关系），`+` 表示必须、`-` 表示排除。结果按会话折叠，点开后滚到那条消息并短暂高亮；若该条不在最新几轮，列表上方可以回到最新。子代理会话不参与搜索。从地址 `/tasks/{id}` 进入（含飞书卡片「会话详情」）时，会展开该会话所在分组；若该会话排在分组默认只显示的前几条之外，也会把它露出来并滚动到对应一行（0.0.182 起）。右侧任务检查器显示执行模式、权限档位、上下文 token、子任务与子智能体入口；点击任务信息区的上下文徽标可打开「上下文详情」抽屉，透视下一轮请求的构成与手动治理（见下文「上下文透视与手动治理」）；子代理会话的徽标只读，仅显示上下文占用。接近上下文上限时会自动压缩历史。聚焦模式下列表加载完成后新建任务会立即出现在聚焦列表，不必再手动刷新；当前会话若在「历史」折叠区，进入时会展开该区。

## 会话智能体身份

已有会话的当前 Agent 出现在两个位置（0.0.323 起）：主会话 Tab 的图标（换成 Agent 头像，开了多个 Tab 时可见）、右侧任务检查器最上方的「智能体」分区（头像 + 名称 + 一句话描述）。两处读同一份身份：优先取当前会话绑定的 Agent 记录，Agent 被停用或当前不可见时回退到会话里记录的名称，并标灰「已停用或不可见」。没有归属 Agent 的历史/系统会话不显示头像与分区。

会话创建后 Agent 也可以换（0.0.380 起，0.0.383 起改从检查器进入）：右侧任务检查器「智能体」分区展示头像、名称和一句话描述，主会话下点击这块信息即可打开可搜索的选择列表，确认后下一轮生效——系统提示词、Skill / MCP / 经验库、子代理预设都按新 Agent 构建；会话已显式选过模型则模型保持不变，未显式选则自动跟随新 Agent 的默认模型；会话级审批放行规则保留。运行中也能切，不打断当前轮。边路任务和子代理的智能体分区只读，不提供切换。检查器即时反映当前绑定。

后台子代理通过 `subagent_followup` 追问或纠偏时，复用聊天历史，但新一轮会重置该子会话的进度待办（包括已完成和未完成项），不再累计上一轮任务。运行中纠偏先等待旧执行结束，再创建新一轮；追问被拒绝或创建事务失败时保留原待办。同一轮失败重试不重置待办，主会话与其他子代理不受影响；重试成功后父代理收到完整结论，不会被进度预览截断。

## 上下文透视与手动治理

检查器「上下文详情」抽屉（点击任务信息区上下文徽标打开，0.0.239 起为页签、0.0.244 起改为抽屉）把"模型这一轮到底看到了什么"变成可见（主会话 / 边路任务可打开抽屉；子代理会话只显示只读占用徽标，不提供入口）。数据与构建请求同源、随上下文水位事件一并推送，只读透明化，不改发送内容：

- **上下文容量与构成**：抽屉顶部为「上下文容量」卡片——一行给出「估算 / 窗口（占比）」，下方一条三段式色调进度条（<60% 常规、60–85% 提示、>85% 告警），冷启动无 token 数据时该卡片留空。下方「上下文构成」按 token 从大到小列出系统提示词、系统工具、对话消息、压缩摘要，以及长期记忆 / 最佳实践经验 / 技能 / 工作区规则等注入型分节，每行为圆点 + 标签 + 占比 + token。上传文件的固定说明计入「系统提示词」，不单独成节。容量是模型实际占用（优先用返回的输入 token）。构成各节按字节估算的比例分摊到这个总数，所以合计与容量一致；压缩摘要已经算在会话消息里，单独列出但不重复计入。构成是上一次请求的快照，刷新后仍在；从未发起过任务的会话暂无构成明细。
- **手动整理上下文**：「立即整理」与「上次摘要」并排，都是轻边框按钮。「立即整理」在会话空闲时立即压缩（越过自动阈值）；运行中点击会排队，在本轮工具结束后执行，并提示"将在本轮工具结束后执行"。若本轮之后模型直接以纯文本结束、不再调用工具，也会在本轮退出前执行。压缩进行中发送消息会提示会话忙、结束后恢复。手动压缩生成的分隔线在消息区标注"手动整理上下文"，位置排在该轮最终回复和它的文件变更之后，作为轮次边界；自动整理关闭（配置 `harness.compaction.enabled=false`）时手动按钮仍可用。
- **上次摘要**：点「上次摘要」展开最近一次压缩摘要全文，附压缩次数、压缩模型与更新时间；再点「收起摘要」折叠。无压缩历史显示空态。切换会话后丢弃上一会话尚未返回的摘要，新会话打开面板时重新读取。摘要沿用站内脱敏视角（工具结果里被脱敏的内容在摘要中同样是脱敏形态，不做二次脱敏，仅会话属主可读）。
- **工具结果截断徽标**：后端把工具输出截到该工具自身上限时（如 `read_file` 大文件、`grep_search` / `glob_search` / `open_web_page` / `shell_session` 命中截断），对应工具卡片显示「输出已截断」徽标——表示展示的是后端截断后的内容，与卡片本地"展开完整输出"（前端 4000 字符折叠）并存、含义不同。纯文本（非结构化）工具输出不带此徽标。

## 运行轨迹

检查器里的任务状态徽标（任务信息区的「执行中 / 已完成 / 失败 / 已取消」等状态）在中心 Tab 打开「运行轨迹」面板。主会话、边路任务、子代理视图都能点：边路 / 子代理的轨迹单独开一个 Tab，标题带来源任务名（如「轨迹 · 提交代码并部署」），与主会话的「轨迹」可同时开着对照；边路 / 子代理轨迹 Tab 刷新后不还原，重新点徽标即可。打开轨迹后右侧边栏跟着轨迹所属会话走——从边路任务 / 子代理视图点进来时，边栏的标题、状态、上下文、进度、模型都是那个会话的，不会退回主会话；点主会话自身的轨迹则仍是主会话视角。一个 run = 从一条用户消息到下一条用户消息之前，轨迹把这段时间摊开：每轮模型调用的耗时、首字、重试、token、成本，轮内是这次调用发出的工具（名称、目标、耗时、审批标记）。用来回答"这次任务为什么慢 / 卡在哪"。

- **总览**：面板顶部是会话级汇总——最近 N 次任务（按已加载页数）的成败分布、总耗时、总 token、总成本（任一 run 未配价时不显示）、工具成功率。轨迹是「汇总 → 下钻」型数据：先在这看整体，再决定展开哪个 run。
- **时间概览条带**：展开某个 run 后，明细区顶部是一条三泳道时间带（轮次 / 工具 / 旁路各一条），把每行的开始时刻与耗时投影成色条——用来一眼看出「谁在等谁、并行还是串行」。同一泳道里并行发出去的工具（`Promise.all`）色条会自然重叠，那就是并行。助手轮次的色条分两段：前段是等首字，后段（半透明）是解码。悬停色条约 0.3s 弹出起止时刻与耗时（起止都标「估算」——起点由「结束时刻 − 耗时」推算，没有精确埋点），点色条会自动展开该 run 并平滑滚动定位到对应行（行高亮约 1.2s）。起止估不出来的行（历史行 / 缺字段）不画色条，图例右侧会说明有几项未画。
- **记录详情下钻**：轮次行与工具行（有 `tool_call_id` 的行）悬停时出现「详情」按钮，点开面板内右侧抽屉看这一行背后的原文，不必回聊天记录里翻。工具抽屉四个 tab：「参数」「结果」是服务端存的原文，合法 JSON 可切「格式化 / 原样」（非法 JSON 按原样展示并标注），「计时与元信息」是配对到的模型调用全字段（provider / protocol / stream / effort / 重试 / 首字 / 耗时 / token / 成本 / 错误信息）加派生三行（解码耗时、吞吐量、请求编号），「请求构成」是该轮实际发送的系统提示词原文与工具名清单（见下）；配不上调用记录时后两个 tab 会明确写「未配对到模型调用记录」。轮次抽屉也是四个 tab，默认「回复」：本轮模型回复的 markdown 正文与思考内容折叠块（崩溃恢复 / 中断导致回复没落库时显示明确空态）；「工具」tab 是本轮工具清单，点某行继续跳该工具的抽屉；「计时与元信息」「请求构成」与工具抽屉同口径。`Esc` / 点左侧遮罩 / 右上角 × 都能关：轮次抽屉里点进工具抽屉后，关掉工具抽屉只回到轮次抽屉、逐级回退（0.0.366 起），在顶层抽屉再关才收起整个抽屉；关掉不清缓存（同一行再点直接展开，不打请求）。
- **消息详情抽屉**：展开某个 run 后，明细区顶部（时间条带下方）有常驻的「查看原文」按钮，点开该条用户消息的完整原文——多模态消息合并文本分片并显示「图片 ×N」附件计数，原始分片数组收进折叠详情；编辑重发过的消息标注「已编辑」。不再只有摘要行里的 80 字预览。摘要行本身（含任务名预览文字）点击只做展开 / 收起切换，不开抽屉（0.0.365 起预览不再独占点击）。
- **请求构成**：轮次 / 工具抽屉的「请求构成」tab 展示该轮实际发送的系统提示词原文（`<pre>` 原样，可切「换行 / 原样」，超过采集上限 256K 字符截断并带「已截断」徽标）与工具名清单（chips）。系统提示词与工具清单从 0.0.349 起随每次调用落库，升级前的历史调用显示「未记录（历史行）」，不回填、不猜。
- **计时补全**：轮次行在模型名后显示 provider 徽标，耗时后面依次是解码耗时（总耗时 − 首字）、吞吐量（输出 tokens ÷ 解码耗时）。非流式调用（无首字）、首字晚于结束的异常行、解码为 0 或输出为 0 时显示「—」，不猜也不显示误导性的 0。
- **摘要条与徽标**：每个 run 一行摘要（开始时间、结果状态图标、用户消息预览、耗时、token），默认收起；点行内任意处（含任务名预览文字）展开 / 收起该 run 的轮次明细，完整消息原文入口在展开区顶部「查看原文」；重试 / 慢 / 贵 / 压缩 / 编辑前等过程与阈值类关注点与消息同行平铺；失败 / 中断 / 重试 / 慢 / 贵按严重度描边，正常 run 不打扰。成本与工具成败数不上摘要行：成本看总览与各轮，工具成败看总览的工具成功率与展开后的 ✓/✕。token 百万级按 M 折算。
- **轮级徽标**：每轮的 中断 / 失败 / 重试 N / 慢 / 贵 都是彩色徽标，和 run 级徽标读同一份数据——run 徽标出现「重试」时，展开后必然能在某一轮的徽标里看到「重试 N」指到具体轮次（曾只有指标行里一行灰色小字，展开后找不到重试点）。
- **分段**：改完已发送的消息再重发时，发送前的调用归入「编辑前」段，重发后的归入「当前」段，两段不混。工具按 `tool_call_id` 归轮；缺 id 的历史行退到按 `created_at` 猜（`message` / `llm_call` 是毫秒精度，同一毫秒里有多条候选时才不猜），单独列为「未挂到轮」。
- **旁路与子代理**：标题生成、上下文压缩等非对话调用计入 run 合计但不占轮序号，列在「旁路调用」；`delegate` / `delegate_followup` 解析出的子代理会话列在「子代理」。
- **实时态**：执行中面板顶部显示「第几轮、是否仍在模型调用中」与进行中工具的已耗时（本地计时——工具结束才有服务端耗时）。执行结束后自动刷新为完成态。
- **阈值**：面板顶部可改「慢」「贵」两个阈值（浏览器本地记住），决定哪些轮打徽标。「慢」按单轮耗时；「贵」按单轮成本（面板每行展示的「成本」同口径，单位元，保留三位小数），模型未配置价格的轮次一律不算贵。切换后对新拉取的轨迹生效，历史阈值偏好会重置一次默认值（慢 60s / 贵 0.5 元）。
- **导出**：JSON（结构与接口一致）与 CSV（列口径与管理后台调用流水一致：成本六位小数、未配价留空、中断写「已中断」）。CSV 另有一列 `provider`（在「模型」之后）：模型行填值，工具行留空。解码耗时与吞吐量是前端派生量，与 CSV 的「落库事实」定位冲突，不进 CSV。
- 轨迹 Tab 与边路任务、子代理 Tab 一样：刷新后回到上次停留的 Tab，「关闭其他文件」不会关掉它。

管理后台「用量分析 → 运行轨迹」另有一份跨会话聚合：最慢的轮、最贵的轮（按 Agent / 用户维度）与工具失败率 Top。

## 新建任务

1. 选 Agent（已在管理后台停用或设为「客户端不可见」的不会出现在列表中）
2. 选 CLOUD 或 LOCAL（浏览器仅 CLOUD）
3. 选/建工作区
4. 选模型（可选，默认模型）
5. 选权限档位（LOCAL 重要）
6. 输入目标并发送

新建任务的「复用已有工作区」下拉条目会带大小与关联会话数副标题（0.0.382 起，来自工作区总览；总览不可用时回落纯目录名，不影响选择）。

## 我的工作区

任务面板头部的文件夹图标打开中央页签「我的工作区」（0.0.382 起）：列出本人工作区根目录下的全部目录（临时工作区、projects 项目、其他自定义目录），表格列有名称（Git 仓库带标记）、类别、占用大小、关联会话（进行中 · 归档）、最近使用，默认按最近使用排序，可切大小 / 名称排序。大小首次进页在后台统计（单目录上限：深度 24 / 条目 20 万 / 30 秒，超限显示「统计超时」可点行内刷新重试），顶部「刷新」强制全部重算。机器人通道工作区（飞书 / 钉钉，在全局根下按机器人聚合）不在本人目录内，不在此页签。

行操作「用于新任务」直接预填新建任务的工作区：项目目录等价于下拉里选中它，临时 / 其他目录以只读「复用」条目带入该目录（新建的 CLOUD 会话就用这个目录，不再自动建新目录；手动改选其他工作区来源即以所选为准）。删除为**物理删除 + 双重确认**：弹层展示目录大小、关联会话计数与进行中引用清单（有进行中会话时不能删），需输入目录名确认；删除后关联归档会话的文件浏览与 Git 面板不再可用（打开时会提示「工作区目录不存在（可能已被删除）」），不做回收站。仅限本人根目录的一级目录与 projects 下的一级项目目录，projects 容器本身不可删。

## CLOUD 云端模式

工具在服务器执行，工作区在 `WORKSPACE_ROOT` 下。云端 `write_file` / `edit_file` 写回已有文件时保留原 CRLF 与 BOM，与 LOCAL 一致。`read_file` / `write_file` / `edit_file` 与 `glob_search` / `grep_search` 的搜索根均支持绝对路径，可读写工作区以外的位置。

- 文件名搜索 `glob_search` 统一异步按需遍历，不依赖 `rg`；minimatch 支持 `**`、花括号、字符组与字面点。包含隐藏文件、不读取 `.gitignore` / `.ignore`，固定排除依赖与构建等目录，遍历不跟随符号链接；访问失败返回 `error`。`head_limit` 须为正整数，仅发现额外匹配才标记 `truncated`，`total_matched` 为返回数而非全量。
- 文件内容搜索 `grep_search` 与之不同：仍区分 `rg` / 无 `rg` 分支，无 `rg` 分支支持异步逐行读取大文件，错误会明确返回；不要套用 `glob_search` 的遍历与计数规则。

完整规则与固定排除目录见 [搜索工具使用说明](tool.md)。

| 工作区来源 | 说明 |
|------------|------|
| 已有工作区 | 复用历史云端目录 |
| 新建 | 可填项目名或临时工作区 |
| Git 初始化 | HTTPS clone，见下文 |

**Git 工作区**：仅 HTTPS；私有库先在「设置 → Git 凭证」配 Token；可指定分支。大仓库 clone 可能 1–2 分钟。

## LOCAL 本地模式

仅 Electron：选本机目录，工具在电脑上执行。浏览器不支持。详见 [electron.md](electron.md)。

## 输入与多模态

清楚描述目标、路径、是否改代码、测试要求。模型开启「支持视觉」时可上传图片分析界面/报错截图。

粘贴**超长纯文本**（≥2000 字符，典型：从 Excel 复制的上千个 ID）时不再插入编辑器，而是自动转成 `pasted-text-N.txt` 待发附件（输入框下方出现附件 chip），发送时走既有附件链路——Agent 用文件工具链精确处理，不用复述这批数据（0.0.378 起）。未达阈值的文本仍是普通粘贴。

## 快捷命令与文件引用

可用 `@` 引用工作区文件；个人快捷指令与个人 Skill 参与快捷面板；Agent 绑定 Skill 时会过滤展示范围。快速改写 `@` 后的关键词时，慢响应不会再覆盖新的搜索结果（0.0.178 起），列表始终对应当前输入。

在助手回复里选中一段文字，会出现「引用」，把选中内容放进输入框上方的引用条。回复底部操作栏没有这个按钮。文件预览和工具变更 Diff 的修改侧可以「引用到对话」，输入框里显示成 `report.py:120-145` 这样的标签；选区超过 200 行或 8KB 时只带行号、不把片段贴进消息。终端输出和 Git Diff 不能引用。安卓没有选区浮钮。这些引用发出去就是普通用户消息文本，编辑重发时仍是原文。

## 回复、思考与工具

会话中可见：普通回复、思考块、工具调用、文件变更、终端输出、上下文/压缩提示。改代码后请检查工具结果与 diff。模型流中断并自动重试时，当前轮已完成的说明和工具调用留在画面上，只丢掉这次未完成的生成；刷新也可从历史恢复。

回复里的结构化内容直接渲染成图和公式（0.0.350 起）：` ```mermaid ` 代码块原位渲染为 SVG 图（图下方「查看源码」折叠回代码块、复制按钮可用；渲染失败保持代码块形态不打断阅读）。气泡里的图被 CSS 缩到容器宽，宽架构图（数千 px）的基准字号会被压到读不了，故点图（触屏没有 hover，点图上常驻的「放大」按钮）进全屏查看器：5%~400% 离散档位缩放，`＋`/`－` 逐档切换，点倍率数字回到 100%，「适应」按舞台宽把整图收进来（只缩不放，小图不虚胖）；打开时若「适应」会把文字压到 12px 以下，默认退到 75% 先保可读，看全靠「适应」或往低调；Esc 或点遮罩关闭（0.0.360 起）。行内 `$...$` 与块级 `$$...$$` LaTeX 公式由 KaTeX 渲染（价格语境如「$5 和 $6」不会被误判成公式），Markdown 表格右上角 hover 出现「复制 Markdown / 复制 CSV」按钮。三者在聊天、文件预览、运行轨迹、分享页共用同一渲染链路；mermaid / katex 均按需加载，不含图和公式的会话首屏体积零增长。任务执行中（流式）的回复暂以代码块形态显示，任务结束后自动出图。

后台子代理完成时，主会话只显示一行通知卡片（点击进入该子代理会话查看详情），不再把子代理的完整输出铺在对话里；执行失败/取消时卡片下方保留一行原因摘要，原因过长时默认折叠、可展开全文（0.0.219 起）。卡片由服务端 `assistant_message_saved` 帧实时推送，盯着会话看也会即时出现，无需刷新页面（0.0.238 起；此前只有刷新后才补出来）。

主聊天切换会话时，对话窗口显示转圈与“正在加载历史对话…”提示：无消息时居中展示，有缓存时保留内容并轻量提示，加载结束后自动消失。切换后自动定位到最新消息；历史加载和异步 Markdown 渲染完成后继续对齐底部。主动向上滚动可暂停自动跟随，回到底部后恢复；再次切换进入会话会重新定位。靠近顶部可加载更早的历史，旧会话未完成的分页不会改变当前会话的滚动位置。

长会话导航（0.0.351 起）：对话区右缘浮动把手点开「轮次目录」，按已加载轮次列出序号 + 用户消息摘要 + 时间 / 步数耗时，点击即定位到那一轮的用户消息并高亮（执行中的轮次不列入；目录只索引已加载轮次，上滑分页补齐后自然更新）。

编辑最后一条用户消息并重发时，失败回滚和收尾刷新都针对开始编辑的那条会话。Agent 仍在处理时切到别的会话，失败不会把当前屏幕的消息整表换成编辑前的对话。

助手回复底部操作栏有「Fork 到边路任务」按钮（复制、点踩旁边），只出现在该轮已经完成的最终回复上，展开后的执行步骤没有这个入口。按轮分叉：点哪一轮的 Fork，边路任务就继承那一轮及其之前的全部内容，之后的一律不要，输入内容即可基于那个时间点接着聊，不必再手动切继承方式（0.0.219 起）。分叉任务的 Tab 标题按首条消息自动生成，悬停 Tab 显示来源（该轮用户消息摘录 + 时间）。落在会话压缩边界之前的轮次也能分叉，边路任务从第一条消息起拿到原始历史、不带摘要；「+ 边路任务」里的「Fork 主会话」单选仍表示全量分叉。分叉后主会话被编辑重发截断了那一轮时，边路任务发送会收到明确错误。

同一操作栏还有「分享会话」图标（0.0.286 起），点开与任务列表右键「分享…」完全相同的弹窗：查看 / 复制链接、刷新快照、撤销分享，匿名链接（带过期）开关也一致。主会话与边路任务窗口都能用；未创建会话时不显示入口（新建会话中心态、边路占位 Tab），只读分享页自身也不再出现该图标。

边路任务窗口（含深层边路）具备与主会话完全一致的 fork 入口：每轮助手回复的「Fork 到边路任务」按钮、窗口右下角「+ 边路任务」、占位 Tab 的继承单选（0.0.238 起）。从边路任务发起时，新边路任务的父会话就是当前边路任务，「边路的边路」可继续再分叉、不做层级限制；占位继承单选文案按来源动态化（来源为主会话显示「主会话摘要 / Fork 主会话」，来源为边路显示「来源会话摘要 / Fork 来源会话」），模型与权限级别的缺省值跟随来源边路会话（来源改过这两项时不再回落主会话）。右侧检查器「边路任务」列表平铺展示主会话全部后代边路任务（不缩进），深层任务的状态变化实时刷新；任务列表页主会话卡片上的执行中 / 未读徽标同样计入全部深层后代。搜索命中深层边路会话时，点击结果会跳转到其根主会话并打开该边路 Tab。

## 回复引用溯源

模型用联网搜索 / 打开网页拿到外部信息作答时，回复正文里被引用的说法旁边会出现小号引用上标（形如 [1]），回复末尾（文件变更面板之前）跟着一个「来源 N」区，按顺序列出本轮实际引用过的网页标题与域名（0.0.282 起）。点上标跳到来源区对应条目并高亮一闪，点来源条目在新标签页打开原网页。

来源不是模型自己说了算：服务端在本轮联网搜索 / 打开网页的工具结果里收集真实 http(s) 链接构建白名单（最多 20 条、按出现顺序编号），只有能对上白名单的引用标记才会渲染出来。模型编造了不存在的来源、编号越界、或者这一轮根本没联网时，界面和以前完全一样——不会出现点了打不开的空上标，正文也不会残留 `[^n^]` 之类的原始记号（导出、分享、以及飞书 / 钉钉 / 微信渠道下发的回复同样如此）。

来源 ≥4 条时默认折叠成一行「来源 N」按钮，点「展开 / 收起」切换；少于 4 条直接平铺。

## 工作区文件与 Git 差异

浏览文件树、查看内容与 Git 变更（不自动 commit/push）。CLOUD 读服务端，并可以在文件树上新建、重命名、删除、移动、复制和上传；删除是物理删除，确认框会列出路径。Agent 正在写同一路径时会先提示，默认取消。LOCAL 只读本机，写操作仍用系统文件管理器。工具栏只保留「管理」（打开文件管理器）与「刷新」，上传走右键「上传到此处」或拖拽（0.0.286 起）。

「文件管理」页签（0.0.281 起）：右侧文件树工具栏的文件夹图标，在中心 Tab 区打开整幅文件管理器，侧边窄栏放不下的操作用整幅空间做。图标 / 列表双视图（偏好本地记住），按名称、大小、修改时间排序，目录恒排在文件前。可上传文件 / 文件夹（按钮挑选，或把文件、目录拖到窗口空白处与目标目录上）、新建文件 / 文件夹、重命名、删除（物理删除，确认框列出全部路径，目录提示连同内容一并删除）、剪切 / 复制 / 粘贴（与文件树共用同一剪贴板，不能跨会话粘贴）、拖拽移动（不能拖进自己或自己的子目录）、下载（多选时批量下载文件，目录打包成 zip）、复制绝对路径 / 复制相对路径（右键菜单与底栏「复制路径」下拉两个入口，多选逐行拼接；0.0.334 起 CLOUD 模式绝对路径不再复制成相对路径）、添加到聊天、右键「在文件树中显示」回跳文件树并展开选中。Ctrl/Cmd 点选多选、Shift 范围选、Ctrl/Cmd+A 全选，Enter 打开、F2 重命名、Delete 删除、Ctrl/Cmd+C/X/V 复制剪切粘贴。面包屑与前进 / 后退在各目录间导航；顶部搜索框按文件名递归整个工作区（最多 100 条），点击结果跳到所在目录并选中该条目。窄视口（手机 / 安卓壳）下图标视图自动收紧为紧凑密度，底部操作按钮单行横向滚动（0.0.286 起）。仅 CLOUD 模式可用，LOCAL 侧边栏行为不变。

**文件预览格式扩展**（0.0.354 起）：文件树双击打开的文件，除既有的 Markdown / PDF / 图片 / 文本外，新增四类可直接阅读——CSV / TSV 渲染成表格（分隔符自动识别，5000 行截断，hover 出现「复制 CSV / 复制 Markdown」）；zip 展开成条目列表（名称 / 大小 / 压缩率，点条目在覆盖层里预览文本、图片、PDF，其他类型与超大文本直接单条目下载）；xlsx / xlsm / xltx 渲染成多 sheet 表格（sheet 标签切换，同样支持复制）；docx 转成排版后的文档正文。音视频（mp4 / webm / mov / m4a / mp3 / wav / flac / ogg）直接内嵌播放。所有格式共用顶部工具条：刷新、下载（LOCAL 模式为「在 Finder 中显示」）、文件信息。安全与上限：zip 条目数 / 解压总大小 / 单条目超限、表格超 20MB、文档超 10MB、媒体超 50MB 时降级为「下载后查看」并给出一键下载出口，不做半截渲染；解析库按需加载，不含这些格式的会话首屏体积零增长。

新建的 Markdown 文件在变更 diff 中可切「预览 / 源码」，两种视图都会正常渲染；后台 Git 状态刷新不会把正在看的源码打回预览（0.0.178 起修复源码视图空白）。中心区 Tab 右键「关闭其他文件」只关文件与 diff Tab，不再连带关掉边路任务 / 子代理 Tab（0.0.178 起）。

CLI 只读诊断：`mao file workspace-*`（见 [file.md](file.md)）。

## 停止与继续

运行中可停止；停止后可继续发消息。运行中发的消息进入待发送队列，可「立即发送」插队；发送失败时该按钮会自动复位并可重试，不会让整个队列的「立即发送」一起失效到本轮执行结束（0.0.178 起）。队列展开后每条消息左侧有拖拽块，按住拖动可调整发送顺序（0.0.236 起）。刚打开会话、队列还没经过一次推送时也可以拖（0.0.251 起）。会话空闲时点停止只做一次「待取消」登记，不会把从未运行过的任务标成「已取消」（0.0.177 起）。断线时点工具审批的「批准 / 拒绝」会提示发送失败并把审批项放回队列，可恢复网络后重试，不会出现审批消失而任务仍在等待的假死。Side Task 可并行子会话；子智能体由 `delegate` 工具创建，在检查器中查看。边路任务点停止、边路/子代理点重试时，若网络不可用会提示失败并保持原按钮可用，不会把停止入口关掉或把重试按钮卡死。

## 终端

顶栏终端按钮（`Ctrl+` `）打开底部终端面板，标签按任务隔离：只显示当前任务的终端。

| 任务模式 | 客户端 | 是否可用 |
|----------|--------|----------|
| CLOUD | Electron / Web / 安卓 | 可用（服务端 bash，需 `terminal:use` 权限） |
| LOCAL | Electron | 可用（本机 shell） |
| LOCAL | Web / 安卓 | 不可用（提示「本地任务的终端仅在桌面客户端可用」） |

**云端终端**：跑在后端服务器上的交互式 bash，工作目录为任务工作区，环境变量与 Agent 的 Shell 工具一致（虚拟 HOME、`GIT_TOKEN_*`、`GIT_ASKPASS`、`MAO_TOKEN`、`ECP_TOKEN`（有 ECP 票时）、`MAO_TASK_NAME`），首次使用写入默认 `.bashrc`。权限 `terminal:use` 默认只授管理员角色；无权限时按钮置灰并提示原因。

- **断线**：网络抖动或切页后自动重连并重新接入原终端，回放最近输出（默认 256KB，超出只截掉超限部分并提示已截断，0.0.177 起单帧超过上限也保留最近输出而非整段空白）；输出过快时会丢弃部分内容并提示。
- **切任务 / 收起面板**：会解绑云端终端（服务端进程继续跑），切回或重新打开时自动接入并回放输出。解绑后的终端开始计空闲时间，长期不用会被回收。
- **关闭最后一个标签页**：终端面板自动收起，不留空面板；下次打开会自动新建或恢复终端。
- **多窗口**：同一终端只能有一个窗口接收输出，被其他窗口接管后面板顶部出现「重新接管」按钮，点击即可夺回。
- **后端重启**：已有终端不恢复（预期行为），重新打开即可。
- **自动回收**：空闲超时、最长存活、每任务/全局上限见 [settings.md](settings.md) 的 `terminal.*`；删除任务会一并关闭其终端。
- **搜索**：面板内 `Ctrl+F` 打开搜索栏（上一个 / 下一个 / 结果计数，`Esc` 关闭）。
- **安卓**：底部虚拟按键条（Esc / Tab / Ctrl 粘滞 / 方向键 / Ctrl+C / Ctrl+D / 粘贴），软键盘弹出时面板自动避让。
- **移动端输入法**：xterm 的隐藏输入框会累积已输入内容，移动端输入法提交字符时可能被整段重发（[xterm.js#6078](https://github.com/xtermjs/xterm.js/issues/6078)）。触屏端已安装清扫器（`desktop/src/utils/terminal-ime-guard.ts`）在按键后清空该累积值，桌面端保持 xterm 原生行为。

云端终端没有路径沙箱与命令白名单，权限等同后端服务账号，仅应授予受信任的管理员。

## 设置

顶栏头像左侧的齿轮图标（或头像菜单里的「设置」）进入设置页（个人信息、Git 凭证、消息通知、渠道绑定、MCP、技能、指令、定时任务、开放接口等）。齿轮与「我的指令」书本图标在设置页内隐藏，避免在设置页里重复放置进入设置页的图标。头像下拉菜单还有「我的指令」「站内收件箱」两个快捷入口：前者与顶栏书本图标等效（打开「我的指令」抽屉），后者打开站内收件箱抽屉。主题色（浅色 / 深色 / 跟随系统）在「设置 → 个人信息」顶部切换。

## 我的指令

顶栏右侧书本图标（或头像菜单「我的指令」）打开「我的指令」抽屉：与「设置 → 我的指令」页同一套管理界面，含「我的指令 / 系统指令」双 Tab，可新建、编辑、复制、删除个人指令。设置页 Tab 页保留原样。

## 定时任务

Agent 可用自然语言创建定时任务；「设置 → 定时任务」查看、编辑、启用/暂停、删除。会话忙时可能 `QUEUED`。

- 每行「编辑」打开编辑对话框：名称、Cron 表达式、任务提示词、一次性开关、失败重试 / 重试间隔 / 错过补偿都能改（以前只能启停和删除）。
- Cron 边打边校验，实时列出未来 3 次触发时间（北京时间）；改成「固定月 + 日」形态时一次性开关自动跟随，手动拨过开关后以开关为准，不一致时给出提醒。
- 已完结任务保存后若 Cron 还能算出下次触发时间，会自动重新激活（恢复为进行中）并提示已切回「进行中」Tab。
- 行内始终显示重试 / 间隔 / 错过补偿的当前值（默认值弱化显示）；启停走行内开关，编辑对话框不改运行状态。

## 信号哨兵

「设置 → 信号哨兵」盯一个外部接口：填地址（http/https，不支持内网）、方法、请求头、轮询间隔与判定模式（内容哈希 / JSON 字段 / HTTP 状态码），再写提示词模板（可用 `{name}` `{url}` `{diff}` 占位）。按间隔自动探测，判定值变化时自动开一次 Agent 会话并把新旧值摘要交给它处理。

- 保存前可点「立即测试」看一次真实探针结果（状态码、耗时、判定哈希、响应体样本），不触发、不写库。
- 首轮轮询只建基线不触发；编辑探测地址 / 方法 / 请求头 / 请求体 / 判定模式 / 提取路径会重置基线。
- 失败按 `间隔 × min(2^失败次数, 32)` 分钟退避；连续失败 5 次自动停用并发站内信，需手动重新启用。
- 每用户最多 20 个哨兵；每次变化 = 一次 Agent 运行，会计入用量。
- 请求头与请求体加密存储，列表回显时敏感请求头打码；详见 [signal-watcher.md](signal-watcher.md)。

## 自定义 HTTP 工具

自定义 HTTP 工具由**管理员**在管理后台配置并关联到具体 Agent（0.0.327 起，客户端不再提供「我的工具」入口）：管理员填工具名（slug）、展示名、用途说明、请求方法、URL、固定请求头、参数定义与请求体模板（`{{参数名}}` 占位），再在 Agent 编辑表单里把工具关联到该 Agent，之后该 Agent 的会话就能在对话里按需调用。

- 工具 schema 不进模型工具列表，只在提示词目录里列名；模型先查参数再调用，因此「用途说明」要写清什么时候该用这个工具。
- 可写工具（`read_only` 关闭）在目录里标「可写」——调用时**没有审批确认**，请只封装可信端点。
- 敏感请求头（Token / Key 等）加密存储、保存后掩码回显，编辑时留空表示沿用原值；试运行需要真实值。
- 默认拒绝访问内网地址；确需访问请联系管理员在「系统设置 → 工具与终端 → 自定义 HTTP 工具」按 CIDR 网段放行。
- 详见 [http-tool.md](http-tool.md)。

## 开放接口

「设置 → 开放接口」管理三样东西：API Token（REST 触发 Agent）、入站 Webhook 触发器（外部系统 POST 事件，HMAC-SHA256 验签）、出站订阅（任务完成 / 失败、提问待答回调到自建 HTTPS 端点）。

- 页面顶部「接口文档」卡片可**查阅**完整调用说明（弹窗内渲染：鉴权、端点与字段、签名算法、错误码、排障），也可**下载 Markdown**（`mao-open-api.md`）或**复制 Markdown** 交给外部系统。文档随桌面端版本内置，不依赖外部站点。
- Token 明文加密留存，列表里「复制 Token」可随时再取；泄露请立即吊销。每人最多 20 个未吊销 Token，默认 90 天过期；一小时内连续失败达到阈值会自动停用，可手动重新启用。
- Token / 触发器卡片上的「调用记录」看自己的调用流水；管理后台「开放调用」看全量、统计与导出。
- 端点契约与命令行等价操作见 [open-api.md](open-api.md)。

## 消息通知

「设置 → 消息通知」：钉钉或飞书机器人 Webhook；先「发送测试通知」再保存。Webhook 加密保存，生产配置 `APP_NOTIFICATION_WEBHOOK_SECRET`。

开启后除任务完成/失败通知外，主会话 Agent 发起提问（`ask_user_questions`）时也会收到「提问通知」：你不在线（无客户端连接）则马上排队发出；桌面端仍连接、但 3 分钟没作答也会发。本地工具审批同样在 3 分钟无人处理时推一条，只含会话标题和固定说明，不含待执行的命令和参数。人在发出前作答、批准、拒绝或超时，这条还没发出的提醒会被取消。回到会话后问题自动重新展示。若同时堆积多组提问，按到达顺序逐组作答，头部计数显示进度（0.0.178 起；此前只有最后一组能回答）。飞书会话不提供该工具（0.0.200 起重新屏蔽），不会触发提问通知。前台委派和后台子代理不会向用户提问（0.0.189 起）。

## 任务收件箱

顶栏头像菜单的「站内收件箱」是站内通知中心（0.0.235 起）：任务完成 / 失败、`ask_user_questions` 提问待答、LOCAL 审批待办、后台子代理结果回传、Webhook 触发器停用、预算提醒统一汇入。点击条目标记已读并跳回关联会话；定时任务产生的条目带「定时任务」徽标，子代理条目按终态显示「已完成 / 执行失败 / 已取消」；预算提醒条目显示「预算提醒 / ¥」徽标且不跳会话（成本越线不属于某个会话）；关联会话被删除时降级为提示不白屏。抽屉内可只看未读、加载更多、全部已读。抽屉宽度 `min(420px, 100vw - 32px)` 自适应，安卓窄屏不被裁切。

提问被回答 / 取消 / 超时、审批被批准 / 拒绝 / 超时后，对应条目自动置已读（仍可回看）。

「设置 → 消息通知 → 站内收件箱」分区可按类型开关（任务完成 / 提问待答 / 审批待办 / 子代理完成 / 预算提醒，默认前四开、子代理完成关），独立保存、与上方 Webhook 配置互不影响。Electron 桌面端另有「系统通知」总开关：窗口未聚焦 / 最小化 / 隐藏到托盘时，由主进程把新增条目弹为系统通知（窗口隐藏也能收到），点击通知恢复窗口并跳转对应会话，macOS dock 角标跟随未读数；系统授权被拒时给出可读提示，站内徽标不受影响。`WEIXIN_REPLY_WINDOW_CLOSED`、`DAILY_DIGEST` 等无 kind 开关的条目不受五类开关门控，窗口失焦时同样弹系统通知。抽屉内条目自身仍有未读标识，顶栏与菜单入口不再显示未读红点徽标。

## 每日运营摘要

「设置 → 消息通知 → 每日运营摘要」：默认开，每天 09:30（Asia/Shanghai，可改）汇总昨天的任务成败与失败原因 Top3、定时任务执行与自动暂停、哨兵触发与自动停用、审批待办挂起数、Token 成本 Top3（未配价调用单独计数）、开放接口调用与拒绝数，写入站内收件箱（「每日摘要」条目，📅 图标）；六项全空的「安静日」不写消息。按天一次性生成，重启不重复，停机跨天恢复后补发前一日。勾选「同时推送到出站订阅」后，配了 `digest.daily` 事件订阅时同步推送（结构化 + Markdown 双格式 payload）；无订阅时该勾选框禁用。「立即发送昨日摘要」可随时试发（不改变当天正式推送）。收件箱里点「每日摘要」打开详情对话框：六板块分区展示（空板块不渲染），失败任务 / 审批项可打开关联会话，成本板块跳「我的用量」，定时任务 / 哨兵板块跳对应设置页。REST 细节见 [inbox.md](inbox.md)。

条目保留 90 天。REST 细节见 [inbox.md](inbox.md)。

## 渠道绑定

「设置 → 渠道绑定」一个页面里并列三个渠道 Tab（微信Bot / 飞书机器人 / 钉钉Bot），分别查看绑定状态、发起绑定与解绑。三个 Tab 懒加载，只拉当前点开那个的状态；钉钉授权完成后回调仍回到本页并自动选中钉钉 Tab。地址带 `?tab=weixin|feishu|dingtalk` 可直达某个 Tab。

### 微信Bot

扫码绑定；微信内对话，CLOUD 执行工具。Agent/模型由系统设置 `weixin.agentId` / `weixin.modelId` 或默认项决定。绑定后可开关「语音回复」。

CLI：`mao weixin ...`（见 [weixin.md](weixin.md)）。

### 飞书机器人

绑定飞书账号：发起授权 → 在打开的飞书页面完成授权（Electron 内嵌窗口 / 浏览器新页）→ 自动轮询绑定结果。绑定以飞书 `union_id` 为身份锚，绑定一次对所有机器人通用。

绑定后可在飞书内与机器人对话：私聊直接发消息，群里 @ 机器人触发（自动注入最近群聊上下文）。未绑定或缺少有效 ECP 票时收到登录/绑定卡片（按钮跳转授权页）。全站启用 ECP 飞书登录后，仅绑定仍不够，还须用同一邮箱完成 ECP 飞书登录写入有效凭证；凭证过期后再发消息会再次收到登录卡片。解绑后机器人无法识别身份，原工作区与会话保留。

详见 [feishu-bot.md](feishu-bot.md)。

### 钉钉机器人

绑定钉钉账号：发起授权 → 在钉钉页面确认 → 本页轮询绑定结果。一个钉钉 userid 对应一个 Mao 用户。未绑定的人在钉钉里会收到「点我绑定」短链，登录后再跳到钉钉授权。解绑后机器人认不出这个人，原会话和工作区保留。

详见 [dingtalk-bot.md](dingtalk-bot.md)。

统计周期：今日、昨日、本周、上周、本月、上月、近 7 天、近 30 天、自定义（默认今日）。上周/上月分别是上一个完整自然周（周一起点）与上一个完整自然月；「自定义」选中后出现日期区间选择器，起止日都由用户选，默认最近 7 天。选今日/昨日时趋势图自动按小时分桶，其余周期按天。Token 数值统一按 K/M/B/T 折算（667,577,705 → 667.6M），趋势纵轴按窗口峰值自动选单位（如 50M、100M、1B）；缓存命中率在没有调用的时间点断开而非归零。成本按模型价格填写口径估算，未配置价格的调用不计入（总览卡片下方有脚注）。数据仅限当前登录用户自己的调用，无需额外权限。对应接口：`GET /v1/llm-calls/me/summary`、`GET /v1/llm-calls/me/trends`（详见 [llm-call.md](llm-call.md)）。

输出速度（0.0.364 起）：口径统一为「输出 tokens ÷ 解码耗时」（解码耗时 = 总耗时 − 首字耗时），明细列逐行实时算出；总览卡片与趋势图是窗口内加权平均（Σ输出 ÷ Σ解码秒），不随分页或单行极值波动。非流式调用没有首字耗时、首字晚于结束的异常行、解码为 0 或输出为 0 时一律显示「—」，不用总耗时凑数、不显示误导性的 0。后端自 0.0.364 起在汇总 / 趋势接口返回 `decodeTokens` / `decodeMs` 聚合字段（只统计可解码调用），历史数据同样可算，无需迁移。运行轨迹面板的调用元信息沿用同一口径，两处数字一致。

REST 非对话操作统一用 `mao` CLI（本 Skill），见 [SKILL.md](../SKILL.md)。

## Git 管理器（中央 Tab）

会话中心区的「Git」页签（0.0.371 起），一个会话一个单例页签，与文件 / diff / 文件管理器页签共存。两个入口：任务检查器的 Git 摘要行点击、变更清单工具栏的展开按钮。

- **变更**：工作区变更清单（新增 / 修改 / 删除 / 改名、增删行数、二进制标记），可直接提交 / 拉取 / 推送；点文件在工作区 diff 页签打开。
- **历史**：提交列表按 50 条一页滚动加载，显示短 hash、作者、相对时间与分支 / 标签装饰；展开某条提交看它的文件清单，点文件打开「单提交 diff」页签——页签 id 带提交 hash，同一路径的不同提交可同时打开对照，重命名 / 移动工作区路径后仍指向同一提交。
- **分支**：本地与远端分组，含 upstream、领先 / 落后计数与最近提交；点本地分支切换（有本地改动时自动 stash 并在切换后恢复），点远端分支创建跟踪分支；每行另有「对比」按钮（见下）。
- **Stash**：引用、消息与时间，可应用 / 弹出 / 丢弃（丢弃有二次确认）。
- **对比**：两个分支下拉（基准 / 目标，本地 + 远端全量；进入视图默认预选「当前分支的 upstream（如 origin/main）→ 当前分支」，仅空槽填充，可随时改选或交换）；汇总条以「基准 → 目标」标明方向，并显示两侧领先 / 落后提交数、文件数与总增删行数，文件按目录分组树展示（单链目录压缩为 `a/b/c` 包名样式，改名行显示旧路径，仅基准分支存在的文件带「仅基准分支」标记）；点文件在中心 Diff Tab 打开该文件在两个分支间的 diff——两点语义（`git diff 基准 目标`，直接比较两侧内容，基准侧独有的改动会呈现为删除 / 反向修改）；支持一键交换基准与目标。分支视图的「对比」按钮会切到本视图并把该分支预填到目标槽（基准取默认预选值、可改）。

多仓库工作区顶部用仓库下拉切换；状态栏显示当前分支、detached HEAD 警告、upstream 与领先 / 落后数、远端徽标（悬停显示脱敏后的 URL），「获取」按钮拉取**全部远端**更新（多远端仓库并行一并同步，最坏等待以单个远端的 60 秒超时为界；某个远端失败不影响其余远端，会提示失败的远端名），不可用时按钮上直接说明原因（未配置远端等）。CLOUD 与本地（Electron）模式能力一致；本地模式的写操作同样不自动 commit / push，均由用户显式触发。
