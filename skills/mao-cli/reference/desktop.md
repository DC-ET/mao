# 桌面 Web 端使用

桌面端是普通用户主入口：选 Agent、建任务、对话、工作区、定时任务、通知与设置。开发默认 `http://localhost:5201`；生产多为 `https://mao.example.com/`（管理后台在同域 `/admin/`）。

LOCAL 本机工具需 Electron，见 [electron.md](electron.md)。对话执行也可用 [mao-agent.md](mao-agent.md)。

## 进入方式

| 方式 | 适用 |
|------|------|
| 浏览器 Web | CLOUD 云端模式、Git 工作区、浏览器访问 |
| Electron | LOCAL 本地模式、本机目录与命令 |

## 任务列表与任务面板

左侧任务列表按工作区/项目分组；可搜索、折叠、加载更多。从地址 `/tasks/{id}` 进入（含飞书卡片「会话详情」）时，会展开该会话所在分组；若该会话排在分组默认只显示的前几条之外，也会把它露出来并滚动到对应一行（0.0.182 起）。右侧任务检查器显示执行模式、权限档位、上下文 token、子任务与子智能体入口；点击任务信息区的上下文徽标可打开「上下文详情」抽屉，透视下一轮请求的构成与手动治理（见下文「上下文透视与手动治理」）。接近上下文上限时会自动压缩历史。聚焦模式下列表加载完成后新建任务会立即出现在聚焦列表，不必再手动刷新；当前会话若在「历史」折叠区，进入时会展开该区。

后台子代理通过 `subagent_followup` 追问或纠偏时，复用聊天历史，但新一轮会重置该子会话的进度待办（包括已完成和未完成项），不再累计上一轮任务。运行中纠偏先等待旧执行结束，再创建新一轮；追问被拒绝或创建事务失败时保留原待办。同一轮失败重试不重置待办，主会话与其他子代理不受影响；重试成功后父代理收到完整结论，不会被进度预览截断。

## 上下文透视与手动治理

检查器「上下文详情」抽屉（点击任务信息区上下文徽标打开，0.0.239 起为页签、0.0.244 起改为抽屉）把"模型这一轮到底看到了什么"变成可见（仅主会话 / 边路任务，子代理会话不显示入口）。数据与构建请求同源、随上下文水位事件一并推送，只读透明化，不改发送内容：

- **上下文容量与构成**：抽屉顶部为「上下文容量」卡片——一行给出「估算 / 窗口（占比）」，下方一条三段式色调进度条（<60% 常规、60–85% 提示、>85% 告警），冷启动无 token 数据时该卡片留空。下方「上下文构成」按 token 从大到小列出系统提示词、系统工具、对话消息、交接（压缩）摘要，以及长期记忆 / 最佳实践经验 / 技能 / 工作区规则等注入型分节，每行为圆点 + 标签 + 占比 + token。上传文件的固定说明计入「系统提示词」，不单独成节。容量是模型实际占用（优先用返回的输入 token）。构成各节按字节估算的比例分摊到这个总数，所以合计与容量一致；交接摘要已经算在会话消息里，单独列出但不重复计入。构成是上一次请求的快照，刷新后仍在；从未发起过任务的会话暂无构成明细。
- **手动整理上下文**：「立即整理上下文」按钮——会话空闲时立即压缩（越过自动阈值）；运行中点击会排队，在本轮工具结束后执行，并提示"将在本轮工具结束后执行"。若本轮之后模型直接以纯文本结束、不再调用工具，也会在本轮退出前执行。压缩进行中发送消息会提示会话忙、结束后恢复。手动压缩生成的分隔线在消息区标注"手动整理上下文"；自动整理关闭（配置 `harness.compaction.enabled=false`）时手动按钮仍可用。
- **查看上次摘要**：折叠面板按需读取本会话最近一次压缩摘要全文，附压缩次数、压缩模型与更新时间；无压缩历史显示空态。切换会话后丢弃上一会话尚未返回的摘要，新会话打开面板时重新读取。摘要沿用站内脱敏视角（工具结果里被脱敏的内容在摘要中同样是脱敏形态，不做二次脱敏，仅会话属主可读）。
- **工具结果截断徽标**：后端把工具输出截到该工具自身上限时（如 `read_file` 大文件、`grep_search` / `glob_search` / `open_web_page` / `shell_session` 命中截断），对应工具卡片显示「输出已截断」徽标——表示展示的是后端截断后的内容，与卡片本地"展开完整输出"（前端 4000 字符折叠）并存、含义不同。纯文本（非结构化）工具输出不带此徽标。

## 新建任务

1. 选 Agent（已在管理后台停用的不会出现在列表中）
2. 选 CLOUD 或 LOCAL（浏览器仅 CLOUD）
3. 选/建工作区
4. 选模型（可选，默认模型）
5. 选权限档位（LOCAL 重要）
6. 输入目标并发送

## CLOUD 云端模式

工具在服务器执行，工作区在 `WORKSPACE_ROOT` 下。云端 `write_file` / `edit_file` 写回已有文件时保留原 CRLF 与 BOM，与 LOCAL 一致。`read_file` / `write_file` / `edit_file` 与 `glob_search` / `grep_search` 的搜索根均支持绝对路径，可读写工作区以外的位置。

- 文件名搜索 `glob_search` 统一异步按需遍历，不依赖 `rg`；minimatch 支持 `**`、花括号、字符组与字面点。包含隐藏文件、不读取 `.gitignore` / `.ignore`，固定排除依赖与构建等目录，遍历不跟随符号链接；访问失败返回 `error`。`head_limit` 须为正整数，仅发现额外匹配才标记 `truncated`，`total_matched` 为返回数而非全量。
- 文件内容搜索 `grep_search` 与之不同：仍区分 `rg` / 无 `rg` 分支，无 `rg` 分支支持异步逐行读取大文件，错误会明确返回；不要套用 `glob_search` 的遍历与计数规则。

完整规则与固定排除目录见 [搜索工具使用说明](tool.md)。

| 工作区来源 | 说明 |
|------------|------|
| 已有工作区 | 复用历史云端目录 |
| 新建 | 可填项目名或临时工作区 |
| Git 初始化 | HTTPS clone，见下文 |

**Git 工作区**：仅 HTTPS；私有库先在「设置 → Git 凭证」配 Token；可指定分支。大仓库 clone 可能 1–2 分钟。

## LOCAL 本地模式

仅 Electron：选本机目录，工具在电脑上执行。浏览器不支持。详见 [electron.md](electron.md)。

## 输入与多模态

清楚描述目标、路径、是否改代码、测试要求。模型开启「支持视觉」时可上传图片分析界面/报错截图。

## 快捷命令与文件引用

可用 `@` 引用工作区文件；个人快捷指令与个人 Skill 参与快捷面板；Agent 绑定 Skill 时会过滤展示范围。快速改写 `@` 后的关键词时，慢响应不会再覆盖新的搜索结果（0.0.178 起），列表始终对应当前输入。

## 回复、思考与工具

会话中可见：普通回复、思考块、工具调用、文件变更、终端输出、上下文/压缩提示。改代码后请检查工具结果与 diff。模型流中断并自动重试时，当前轮已完成的说明和工具调用留在画面上，只丢掉这次未完成的生成；刷新也可从历史恢复。

后台子代理完成时，主会话只显示一行通知卡片（点击进入该子代理会话查看详情），不再把子代理的完整输出铺在对话里；执行失败/取消时卡片下方保留一行原因摘要，原因过长时默认折叠、可展开全文（0.0.219 起）。卡片由服务端 `assistant_message_saved` 帧实时推送，盯着会话看也会即时出现，无需刷新页面（0.0.238 起；此前只有刷新后才补出来）。

主聊天切换会话时，对话窗口显示转圈与“正在加载历史对话…”提示：无消息时居中展示，有缓存时保留内容并轻量提示，加载结束后自动消失。切换后自动定位到最新消息；历史加载和异步 Markdown 渲染完成后继续对齐底部。主动向上滚动可暂停自动跟随，回到底部后恢复；再次切换进入会话会重新定位。靠近顶部可加载更早的历史，旧会话未完成的分页不会改变当前会话的滚动位置。

编辑最后一条用户消息并重发时，失败回滚和收尾刷新都针对开始编辑的那条会话。Agent 仍在处理时切到别的会话，失败不会把当前屏幕的消息整表换成编辑前的对话。

助手回复底部操作栏有「Fork 到边路任务」按钮（复制、点踩旁边），只出现在该轮已经完成的最终回复上，展开后的执行步骤没有这个入口。按轮分叉：点哪一轮的 Fork，边路任务就继承那一轮及其之前的全部内容，之后的一律不要，输入内容即可基于那个时间点接着聊，不必再手动切继承方式（0.0.219 起）。分叉任务的 Tab 标题按首条消息自动生成，悬停 Tab 显示来源（该轮用户消息摘录 + 时间）。落在会话压缩边界之前的轮次也能分叉，边路任务从第一条消息起拿到原始历史、不带摘要；「+ 边路任务」里的「Fork 主会话」单选仍表示全量分叉。分叉后主会话被编辑重发截断了那一轮时，边路任务发送会收到明确错误。

边路任务窗口（含深层边路）具备与主会话完全一致的 fork 入口：每轮助手回复的「Fork 到边路任务」按钮、窗口右下角「+ 边路任务」、占位 Tab 的继承单选（0.0.238 起）。从边路任务发起时，新边路任务的父会话就是当前边路任务，「边路的边路」可继续再分叉、不做层级限制；占位继承单选文案按来源动态化（来源为主会话显示「主会话摘要 / Fork 主会话」，来源为边路显示「来源会话摘要 / Fork 来源会话」），模型与权限级别的缺省值跟随来源边路会话（来源改过这两项时不再回落主会话）。右侧检查器「边路任务」列表平铺展示主会话全部后代边路任务（不缩进），深层任务的状态变化实时刷新；任务列表页主会话卡片上的执行中 / 未读徽标同样计入全部深层后代。搜索命中深层边路会话时，点击结果会跳转到其根主会话并打开该边路 Tab。

## 工作区文件与 Git 差异

浏览文件树、查看内容与 Git 变更（只读，不自动 commit/push）。CLOUD 读服务端；LOCAL 读本机。

新建的 Markdown 文件在变更 diff 中可切「预览 / 源码」，两种视图都会正常渲染；后台 Git 状态刷新不会把正在看的源码打回预览（0.0.178 起修复源码视图空白）。中心区 Tab 右键「关闭其他文件」只关文件与 diff Tab，不再连带关掉边路任务 / 子代理 Tab（0.0.178 起）。

CLI 只读诊断：`mao file workspace-*`（见 [file.md](file.md)）。

## 停止与继续

运行中可停止；停止后可继续发消息。运行中发的消息进入待发送队列，可「立即发送」插队；发送失败时该按钮会自动复位并可重试，不会让整个队列的「立即发送」一起失效到本轮执行结束（0.0.178 起）。队列展开后每条消息左侧有拖拽块，按住拖动可调整发送顺序（0.0.236 起）。会话空闲时点停止只做一次「待取消」登记，不会把从未运行过的任务标成「已取消」（0.0.177 起）。断线时点工具审批的「批准 / 拒绝」会提示发送失败并把审批项放回队列，可恢复网络后重试，不会出现审批消失而任务仍在等待的假死。Side Task 可并行子会话；子智能体由 `delegate` 工具创建，在检查器中查看。边路任务点停止、边路/子代理点重试时，若网络不可用会提示失败并保持原按钮可用，不会把停止入口关掉或把重试按钮卡死。

## 终端

顶栏终端按钮（`Ctrl+` `）打开底部终端面板，标签按任务隔离：只显示当前任务的终端。

| 任务模式 | 客户端 | 是否可用 |
|----------|--------|----------|
| CLOUD | Electron / Web / 安卓 | 可用（服务端 bash，需 `terminal:use` 权限） |
| LOCAL | Electron | 可用（本机 shell） |
| LOCAL | Web / 安卓 | 不可用（提示「本地任务的终端仅在桌面客户端可用」） |

**云端终端**：跑在后端服务器上的交互式 bash，工作目录为任务工作区，环境变量与 Agent 的 Shell 工具一致（虚拟 HOME、`GIT_TOKEN_*`、`GIT_ASKPASS`、`MAO_TOKEN`、`ECP_TOKEN`（有 ECP 票时）、`MAO_TASK_NAME`），首次使用写入默认 `.bashrc`。权限 `terminal:use` 默认只授管理员角色；无权限时按钮置灰并提示原因。

- **断线**：网络抖动或切页后自动重连并重新接入原终端，回放最近输出（默认 256KB，超出只截掉超限部分并提示已截断，0.0.177 起单帧超过上限也保留最近输出而非整段空白）；输出过快时会丢弃部分内容并提示。
- **切任务 / 收起面板**：会解绑云端终端（服务端进程继续跑），切回或重新打开时自动接入并回放输出。解绑后的终端开始计空闲时间，长期不用会被回收。
- **关闭最后一个标签页**：终端面板自动收起，不留空面板；下次打开会自动新建或恢复终端。
- **多窗口**：同一终端只能有一个窗口接收输出，被其他窗口接管后面板顶部出现「重新接管」按钮，点击即可夺回。
- **后端重启**：已有终端不恢复（预期行为），重新打开即可。
- **自动回收**：空闲超时、最长存活、每任务/全局上限见 [settings.md](settings.md) 的 `terminal.*`；删除任务会一并关闭其终端。
- **搜索**：面板内 `Ctrl+F` 打开搜索栏（上一个 / 下一个 / 结果计数，`Esc` 关闭）。
- **安卓**：底部虚拟按键条（Esc / Tab / Ctrl 粘滞 / 方向键 / Ctrl+C / Ctrl+D / 粘贴），软键盘弹出时面板自动避让。
- **移动端输入法**：xterm 的隐藏输入框会累积已输入内容，移动端输入法提交字符时可能被整段重发（[xterm.js#6078](https://github.com/xtermjs/xterm.js/issues/6078)）。触屏端已安装清扫器（`desktop/src/utils/terminal-ime-guard.ts`）在按键后清空该累积值，桌面端保持 xterm 原生行为。

云端终端没有路径沙箱与命令白名单，权限等同后端服务账号，仅应授予受信任的管理员。

## 设置

顶栏右侧齿轮按钮进入设置页（个人信息、Git 凭证、消息通知、微信/飞书、MCP、技能、指令、定时任务等）。头像下拉菜单保留「个人信息」快捷入口与退出登录。

## 定时任务

Agent 可用自然语言创建定时任务；「设置 → 定时任务」查看启用/暂停/删除。会话忙时可能 `QUEUED`。

## 消息通知

「设置 → 消息通知」：钉钉或飞书机器人 Webhook；先「发送测试通知」再保存。Webhook 加密保存，生产配置 `APP_NOTIFICATION_WEBHOOK_SECRET`。

开启后除任务完成/失败通知外，主会话 Agent 发起提问（`ask_user_questions`）且你不在线（无客户端连接）时，也会收到"提问通知"，提醒回到对话页面回答；回到会话后问题自动重新展示。若同时堆积多组提问，按到达顺序逐组作答，头部计数显示进度（0.0.178 起；此前只有最后一组能回答）。飞书会话不提供该工具（0.0.200 起重新屏蔽），不会触发提问通知。前台委派和后台子代理不会向用户提问（0.0.189 起）。

## 任务收件箱

顶栏消息图标是站内通知中心（0.0.235 起）：任务完成 / 失败、`ask_user_questions` 提问待答、LOCAL 审批待办、后台子代理结果回传、Webhook 触发器停用、预算提醒统一汇入，图标徽标显示服务端权威未读数（实时推送，重连 / 打开抽屉会重拉）。点击条目标记已读并跳回关联会话；定时任务产生的条目带「定时任务」徽标，子代理条目按终态显示「已完成 / 执行失败 / 已取消」；预算提醒条目显示「预算提醒 / ¥」徽标且不跳会话（成本越线不属于某个会话）；关联会话被删除时降级为提示不白屏。抽屉内可只看未读、加载更多、全部已读。抽屉宽度 `min(420px, 100vw - 32px)` 自适应，安卓窄屏不被裁切。

提问被回答 / 取消 / 超时、审批被批准 / 拒绝 / 超时后，对应条目自动置已读（仍可回看）。

「设置 → 消息通知 → 站内收件箱」分区可按类型开关（任务完成 / 提问待答 / 审批待办 / 子代理完成 / 预算提醒，默认前四开、子代理完成关），独立保存、与上方 Webhook 配置互不影响。Electron 桌面端另有「系统通知」总开关：窗口未聚焦 / 最小化时把新增条目弹为系统通知，点击即聚焦并跳转；未授权时静默降级为站内徽标。

条目保留 90 天。REST 细节见 [inbox.md](inbox.md)。

## 微信 Bot（可选）

「设置 → 微信Bot」扫码绑定；微信内对话，CLOUD 执行工具。Agent/模型由系统设置 `weixin.agentId` / `weixin.modelId` 或默认项决定。

CLI：`mao weixin ...`（见 [weixin.md](weixin.md)）。

## 飞书机器人（可选）

「设置 → 飞书Bot」绑定飞书账号：发起授权 → 在打开的飞书页面完成授权（Electron 内嵌窗口 / 浏览器新页）→ 自动轮询绑定结果。绑定以飞书 `union_id` 为身份锚，绑定一次对所有机器人通用。

绑定后可在飞书内与机器人对话：私聊直接发消息，群里 @ 机器人触发（自动注入最近群聊上下文）。未绑定或缺少有效 ECP 票时收到登录/绑定卡片（按钮跳转授权页）。全站启用 ECP 飞书登录后，仅绑定仍不够，还须用同一邮箱完成 ECP 飞书登录写入有效凭证；凭证过期后再发消息会再次收到登录卡片。解绑后机器人无法识别身份，原工作区与会话保留。

详见 [feishu-bot.md](feishu-bot.md)。

## 钉钉机器人（可选）

「设置 → 钉钉Bot」绑定钉钉账号：发起授权 → 在钉钉页面确认 → 本页轮询绑定结果。一个钉钉 userid 对应一个 Mao 用户。未绑定的人在钉钉里会收到「点我绑定」短链，登录后再跳到钉钉授权。解绑后机器人认不出这个人，原会话和工作区保留。

详见 [dingtalk-bot.md](dingtalk-bot.md)。

## 个人 Skill 与 mao-cli

上传个人 Skill 覆盖同名系统 Skill。「设置」中还可管理 Git 凭证、任务面板偏好等。

## 使用记录

「设置 → 使用记录」查看当前账号的 LLM 调用明细：场景、模型、入/出 Token、耗时与成败；可按场景筛选，会话 ID 可跳转任务。CLI：`mao llm-call me`（见 [llm-call.md](llm-call.md)）。

REST 非对话操作统一用 `mao` CLI（本 Skill），见 [SKILL.md](../SKILL.md)。

## 权限档位与审批（LOCAL）

| 档位 | 说明 |
|------|------|
| 只读 | 搜索/读自动，写与命令需审批 |
| 读写 | 文件读写自动，命令需审批 |
| 智能预审 | 文件读写自动，命令由 AI 预判，高危才需审批 |
| 替我审批 | 文件读写自动，命令与 MCP 由 AI 结合上下文代为审批 |
| 完全权限 | 全部自动，风险最高 |

审批卡片展示待执行命令或变更，可执行/拒绝/展开查看。批准前检查目录、删除、推送、未知脚本等风险。

## Git 凭证

「设置 → Git 凭证」：按**完整主机名**（如 `git.example.com`）存 Access Token，用于 HTTPS clone 与云端 git 操作。仅 HTTPS；push 需写权限。

CLI：`mao git ...`（见 [git.md](git.md)）。

## 常见任务示例

- **分析项目**：选工作区，要求先读 README 与结构，暂不改文件
- **改代码**：明确目标，要求跑测试，审批必要命令
- **排障**：提供日志、复现步骤、相关模块
- **定时任务**：自然语言说明周期与内容，在设置页确认
- **通知**：配置 Webhook 并测试
