# 自定义 HTTP 工具（user-tool）

## 模块职责

让用户把自己的 HTTP(S) 接口封装成 **Agent 可调用的工具**：在「设置 → 我的工具」声明端点 URL、请求方法、参数、固定请求头与请求体模板，之后 Agent 就能在对话里按需调用它。适合「Agent 需要读 / 写某个内部或外部系统，但平台没有现成工具」的场景。

与 MCP 的分工：MCP 是「接一个标准 MCP Server，拿到它暴露的全部工具」；自定义 HTTP 工具是「为单个 REST 端点写一个薄封装」，不需要对方实现 MCP 协议。

与信号哨兵的分工：哨兵是「Mao 定时主动出去看，有变化才开会话」；自定义工具是「Agent 在会话里按需调用」，由模型决定何时用。

## 核心规则

| 项 | 规则 |
|----|------|
| 懒加载宪法 | 工具 schema **一律不进入模型 `tools` 数组**。系统提示词里只有目录分节（工具名 + 展示名 + 用途 + 只读标记）；模型先 `http_describe(工具名)` 取参数定义，再 `http_call(工具名, 参数)` 调用 |
| 执行位置 | 服务端进程原生 fetch 直连（与 `web_search` / `open_web_page` 同款）。CLOUD / LOCAL / docker / CLI / 渠道全模式一致，不做 LOCAL 委托桌面执行 |
| 审批门 | **没有审批确认环节**。`http_describe` / `http_call` 属 `SERVER_ONLY_TOOLS`，不进入审批判定、规则匹配与桌面弹窗；可写工具误调用的代价由 SSRF 基线、只读标记、试运行调试台、per-tool 启停与管理后台失败率观测共同承接 |
| 参数 | string / number / boolean 三型，可设中文说明、必填与默认值；每工具最多 50 个。URL 查询串与请求体模板里的 `{{参数名}}` 占位由执行内核单趟文本替换（不递归） |
| 请求头 | 每工具最多 20 个；键名含 token / secret / key / authorization / cookie 的按敏感值 AES-GCM 加密（密钥 `APP_USER_TOOL_SECRET`），列表与编辑回显打码为 `******`，编辑时回传掩码视为不修改 |
| 超时与截断 | 超时钳制 1000~60000ms（默认 15000）；响应体读满 64KB 即截断并给截断提示 |
| 只读标记 | GET / HEAD 新建时默认只读；只读仅用于目录分节标记与 describe 回显，**不影响执行**（方案二无审批门） |
| 启用上限 | 单用户默认最多启用 20 个（系统设置 `tools.http.maxEnabledPerUser` 可调 1~100）；超限时按名称排序取前 N 个进入可调用集合 |
| 保留字 | 工具名不得与内置工具重名，不得使用 `mcp__` 前缀，不得叫 `http_call` / `http_describe`；slug 规则 `^[a-z][a-z0-9_]{0,63}$`（属主内唯一） |
| 数据隔离 | 全部用户侧端点登录态 + 属主校验；执行链路 userId 只从 sessionId 解析 |

## SSRF 基线

| 项 | 规则 |
|----|------|
| 默认拒绝 | 环回、私网（10/8、172.16/12、192.168/16 等）、链路本地、保留段与云元数据地址（169.254.169.254） |
| 管理员放行 | 系统设置「工具与终端 → 自定义 HTTP 工具 → `tools.http.privateAllowlist`」按 CIDR 网段放行（如 `["10.0.0.0/8","192.168.1.0/24"]`），留空 = 一律按私网拒绝；主机名解析出多个 IP 时**每一个**都必须在名单内才放行（fetch 连哪个地址由运行时择优，只放行命中项会连到未批准网段） |
| 永不放行 | 环回 127.0.0.0/8 与 169.254.169.254 硬拒，先于放行判定；放行清单保存时即拒绝与这两段相交的 CIDR（含 127.0.0.1、169.254.0.0/16、0.0.0.0/0），不留下「配了但不生效」的项 |
| DNS | 请求前解析一次，按解析结果判定；重定向最多跟随 2 跳，每一跳重新判定 |

## 端点

用户级（登录态，本人数据）：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/v1/user-tools` | 我的工具列表（请求头敏感值打码，含参数定义） |
| POST | `/v1/user-tools` | 新建（slug / 展示名 / 用途说明 / 方法 / URL / 请求头 / 参数 / body 模板 / 只读 / 超时 / 启用） |
| PUT | `/v1/user-tools/:id` | 编辑（属主校验；请求头为完整替换语义，敏感值传掩码 = 不修改；省略 `enabled` 时沿用已存启停态，不会把停用工具改回启用） |
| DELETE | `/v1/user-tools/:id` | 删除（级联删参数行） |
| PUT | `/v1/user-tools/:id/enabled` | 启停，body `{ "enabled": true \| false }`；启用时校验单用户上限 |
| POST | `/v1/user-tools/test` | 草稿试运行（**不落库**）：完整定义 + 本次 arguments，走与正式调用同一执行内核；返回 `{ status, body, truncated, notice, durationMs }` 或 `{ error, durationMs }` |

管理级（只读，需 `user_tool:read` 权限）：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/v1/admin/user-tools` | 全站分页清单，筛选 `keyword` / `username` / `enabled`；不含请求头 |
| GET | `/v1/admin/user-tools/stats` | 调用统计（按内层工具名聚合）：调用次数、失败次数、失败率、调用用户数、首次 / 最近调用时间；可按 `slug` 筛选 |

## 模型侧两个内置工具

| 工具 | 入参 | 行为 |
|------|------|------|
| `http_describe` | `{ tool: "工具名" }` | 返回该工具的 URL、方法、参数定义（含中文说明、必填、默认值）与只读标记；仅本人 + 已启用，不发起网络请求 |
| `http_call` | `{ tool: "工具名", arguments: { ... } }` | 校验参数、渲染请求头发请求，返回状态码与截断后的响应体；`arguments` 上限 64KB |

调用失败时返回可读错误（工具不存在 / 未启用 / 缺必填参数 / 类型不符 / SSRF 拒绝 / 连接失败 / HTTP 非 2xx），模型可据此自行修正重试。

## 桌面端与系统设置

- 「设置 → 我的工具」：卡片列表（端点、只读 / 可写、启停）+ 编辑器 + 「测试调用」抽屉（按参数表动态生成表单、默认值预填、展示原始响应与截断提示）。可写工具在编辑器内明示没有审批确认；含已加密请求头时试运行需先回填真实值。
- 管理后台「运行 → 自定义工具」：跨用户清单 + 调用统计，只读。
- 系统设置「工具与终端 → 自定义 HTTP 工具」：`tools.http.privateAllowlist`（CIDR JSON 数组，保存前校验格式并拒绝与环回 / 云元数据相交的网段）与 `tools.http.maxEnabledPerUser`（1~100）。

## 不在范围（P2 / P3）

非交互上下文（定时任务 / 信号哨兵 / 开放接口触发时调用）、导出导入、响应提取语法（JSONPath）、OAuth2 授权流、工具市场 / 团队共享目录、per-Agent 启停覆盖、工具级限流。审批门与「总是允许」规则已随方案二撤销。
